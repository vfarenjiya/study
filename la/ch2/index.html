2. Linear Dependence and Independence of Vectors

Chapter 2 of 11 25 min read

The question left over from Chapter 1

In Chapter 1 we computed two spans in \(\mathbb{R}^2\) that looked different but were identical:

\[ \operatorname{span}\{(1,2)\} = \operatorname{span}\{(1,2),\,(2,4)\} \]

Adding the second vector \((2,4)\) changed nothing — it was already a scalar multiple of the first. But with \(e_1 = (1,0)\) and \(e_2 = (0,1)\), adding the second vector did enlarge the span from a line to all of \(\mathbb{R}^2\). So there is a real, structural difference between these two situations, and it has nothing to do with how many vectors we started with. The question this chapter answers is precise:

Given vectors \(v_1, \dots, v_k\), when does adding one more vector \(v_{k+1}\) strictly enlarge their span, and when does it leave the span unchanged?

The answer will give us two of the most important words in linear algebra — linearly dependent and linearly independent — and from them, the concepts of basis and dimension. Every computational tool in later chapters (Gaussian elimination in Chapter 4, rank in Chapter 5, eigenvalues in Chapter 6) exists to answer variations of this single question.

Dependence: when a vector adds nothing

Let us start with the easier half of the question: when does adding \(v_{k+1}\) to \(\{v_1, \dots, v_k\}\) not enlarge the span? By definition of span (Chapter 1), this happens exactly when \(v_{k+1}\) is already a linear combination of \(v_1, \dots, v_k\):

\[ v_{k+1} = c_1 v_1 + c_2 v_2 + \cdots + c_k v_k \quad \text{for some } c_1, \dots, c_k \in \mathbb{R} \]

Rearranging — moving everything to one side using additive inverses (which exist in any vector space):

\[ c_1 v_1 + c_2 v_2 + \cdots + c_k v_k + (-1) v_{k+1} = \mathbf{0} \]

This is a linear combination of all \(k+1\) vectors that equals zero, and crucially, the coefficient of \(v_{k+1}\) is \(-1\), which is not zero. So we have found a nontrivial linear relation among the vectors — "nontrivial" meaning at least one coefficient is nonzero.

This observation motivates the definition. We say vectors \(v_1, \dots, v_k\) are linearly dependent if there exist scalars \(c_1, \dots, c_k\), not all zero, such that

\[ c_1 v_1 + c_2 v_2 + \cdots + c_k v_k = \mathbf{0} \]

The phrase "not all zero" is the entire content of the definition. If all coefficients were zero, the equation would read \(\mathbf{0} = \mathbf{0}\), which is always true and tells us nothing. Dependence means there is a non-obvious way to combine the vectors to get zero.

Why this definition captures "redundancy"

We motivated dependence via "adding a vector doesn't enlarge the span," but the definition is symmetric in all \(k\) vectors — it doesn't single out a "last" one. Is that a problem? No, because of the following equivalence, which is worth deriving carefully:

Claim: \(v_1, \dots, v_k\) are linearly dependent if and only if at least one \(v_j\) can be written as a linear combination of the others.

Proof (\(\Rightarrow\)): Suppose \(c_1 v_1 + \cdots + c_k v_k = \mathbf{0}\) with not all \(c_i = 0\). Pick any index \(j\) with \(c_j \neq 0\) (such an index exists by assumption). Then isolate \(v_j\):

\[ c_j v_j = -c_1 v_1 - \cdots - c_{j-1} v_{j-1} - c_{j+1} v_{j+1} - \cdots - c_k v_k \]

Since \(c_j \neq 0\), divide both sides by \(c_j\) (scalar multiplication by \(1/c_j\), valid in \(\mathbb{R}\)):

\[ v_j = \left(-\frac{c_1}{c_j}\right) v_1 + \cdots + \left(-\frac{c_{j-1}}{c_j}\right) v_{j-1} + \left(-\frac{c_{j+1}}{c_j}\right) v_{j+1} + \cdots + \left(-\frac{c_k}{c_j}\right) v_k \]

So \(v_j\) is a linear combination of the other vectors. Each step used only vector space axioms (additive inverse, scalar multiplication, distributivity).

Proof (\(\Leftarrow\)): Suppose \(v_j = d_1 v_1 + \cdots + d_{j-1} v_{j-1} + d_{j+1} v_{j+1} + \cdots + d_k v_k\). Move everything to one side:

\[ d_1 v_1 + \cdots + d_{j-1} v_{j-1} + (-1) v_j + d_{j+1} v_{j+1} + \cdots + d_k v_k = \mathbf{0} \]

The coefficient of \(v_j\) is \(-1 \neq 0\), so this is a nontrivial linear relation. The vectors are dependent.

This equivalence is what makes the definition useful: dependence means redundancy. At least one vector in a dependent set is "already there" — it lives in the span of the others and contributes no new direction.

Worked example: detecting dependence by inspection

Are the vectors \(v_1 = (1, 2, 3)\), \(v_2 = (2, 4, 6)\), \(v_3 = (0, 1, -1)\) in \(\mathbb{R}^3\) linearly dependent?

Step 1: Look before computing. Notice \(v_2 = 2 v_1\) — every component of \(v_2\) is exactly twice the corresponding component of \(v_1\). So \(v_2\) is a scalar multiple of \(v_1\), which means \(v_2\) is a linear combination of the others (trivially, of just \(v_1\)). By the equivalence above, the set is dependent.

Step 2: Write the explicit relation. From \(v_2 = 2v_1\), rearrange:

\[ 2 v_1 + (-1) v_2 + 0 v_3 = \mathbf{0} \]

The coefficients are \((2, -1, 0)\), not all zero. This is a concrete nontrivial relation witnessing dependence.

Step 3: Verify arithmetically. Compute the left side component by component:

\[ 2(1, 2, 3) + (-1)(2, 4, 6) + 0(0, 1, -1) = (2, 4, 6) + (-2, -4, -6) + (0, 0, 0) = (0, 0, 0) \]

Confirmed. The key lesson: always inspect for obvious scalar multiples before setting up equations. In exams, many dependence questions are designed to be spotted this way, saving you from unnecessary computation.

Independence: when every vector earns its place

The negation of dependence gives us the other half of the story. Vectors \(v_1, \dots, v_k\) are linearly independent if the only way to get

\[ c_1 v_1 + c_2 v_2 + \cdots + c_k v_k = \mathbf{0} \]

is to take all coefficients equal to zero: \(c_1 = c_2 = \cdots = c_k = 0\). This is called the trivial linear relation. Independence means there are no nontrivial relations — no hidden redundancies, no vector that can be expressed in terms of the others.

Equivalently (by negating the equivalence we proved above): \(v_1, \dots, v_k\) are independent if and only if no \(v_j\) lies in the span of the others. Every vector contributes a genuinely new direction. Adding any one of them to the span of the rest strictly enlarges that span.

The fundamental test: solving a homogeneous system

The definition of independence asks whether a certain equation has only the trivial solution. That equation is a homogeneous linear system, and we can write it in matrix form. Stack the vectors as columns of a matrix \(A = \begin{pmatrix} | & | & & | \\ v_1 & v_2 & \cdots & v_k \\ | & | & & | \end{pmatrix}\). Then

\[ c_1 v_1 + c_2 v_2 + \cdots + c_k v_k = A \begin{pmatrix} c_1 \\ c_2 \\ \vdots \\ c_k \end{pmatrix} = A c \]

So the vectors are independent if and only if the homogeneous system \(Ac = \mathbf{0}\) has only the trivial solution \(c = \mathbf{0}\). They are dependent if and only if \(Ac = \mathbf{0}\) has a nontrivial solution.

This rephrasing is the bridge to computation: Chapter 4 will teach Gaussian elimination to solve \(Ac = \mathbf{0}\) systematically. For now, in small examples, we can solve directly.

Worked example: proving independence from scratch

Are \(v_1 = (1, 0, 1)\), \(v_2 = (0, 1, 1)\), \(v_3 = (1, 1, 0)\) in \(\mathbb{R}^3\) linearly independent?

Step 1: Set up the defining equation. We need to determine whether

\[ c_1 (1, 0, 1) + c_2 (0, 1, 1) + c_3 (1, 1, 0) = (0, 0, 0) \]

forces \(c_1 = c_2 = c_3 = 0\).

Step 2: Expand component by component. The left side is

\[ (c_1 + c_3,\ c_2 + c_3,\ c_1 + c_2) \]

Setting each component equal to zero gives the system:

\[ \begin{cases} c_1 + c_3 = 0 \\ c_2 + c_3 = 0 \\ c_1 + c_2 = 0 \end{cases} \]

Step 3: Solve systematically. From equation (1): \(c_3 = -c_1\). From equation (2): \(c_3 = -c_2\). Therefore \(-c_1 = -c_2\), so \(c_1 = c_2\). Substitute into equation (3): \(c_1 + c_1 = 0\), so \(2c_1 = 0\), hence \(c_1 = 0\). Back-substitute: \(c_2 = c_1 = 0\), and \(c_3 = -c_1 = 0\).

Step 4: State the conclusion. The only solution is \(c_1 = c_2 = c_3 = 0\). Therefore \(v_1, v_2, v_3\) are linearly independent.

Verification mini-example: What if we change \(v_3\) to \((1, 1, 2)\)? Then the third equation becomes \(c_1 + c_2 = 2c_3\) (wait — let's recompute properly). Actually, \(v_3' = (1,1,2)\) gives the system \(c_1 + c_3 = 0\), \(c_2 + c_3 = 0\), \(c_1 + c_2 + 2c_3 = 0\). From the first two: \(c_1 = c_2 = -c_3\). Third equation: \((-c_3) + (-c_3) + 2c_3 = 0\), which is \(0 = 0\) — always satisfied. So \(c_3\) is free; taking \(c_3 = 1\) gives \(c_1 = c_2 = -1\), and indeed \(-(1,0,1) - (0,1,1) + (1,1,2) = (0,0,0)\). The modified set is dependent. Changing one component flipped independence to dependence — this sensitivity is why we need a systematic test (Chapter 4) rather than ad-hoc inspection.

Special cases worth memorizing

Before moving to bases, several edge cases deserve explicit treatment. These appear constantly on exams and in proofs.

A single vector

A set containing one vector \(\{v\}\) is linearly dependent if and only if \(v = \mathbf{0}\). Why? The defining equation is \(c v = \mathbf{0}\). If \(v = \mathbf{0}\), then any \(c\) works (take \(c = 1\)), so there is a nontrivial solution. If \(v \neq \mathbf{0}\), then \(cv = \mathbf{0}\) forces \(c = 0\) (this follows from the vector space axioms: if \(c \neq 0\), multiply both sides by \(1/c\) to get \(v = \mathbf{0}\), contradiction). So: a single nonzero vector is always independent; the zero vector alone is dependent.

Any set containing the zero vector

If \(\mathbf{0}\) is among \(v_1, \dots, v_k\), the set is automatically dependent. Take the coefficient of \(\mathbf{0}\) to be \(1\) and all other coefficients to be \(0\):

\[ 0 \cdot v_1 + \cdots + 1 \cdot \mathbf{0} + \cdots + 0 \cdot v_k = \mathbf{0} \]

This is nontrivial (the coefficient of \(\mathbf{0}\) is \(1 \neq 0\)). So no linearly independent set ever contains the zero vector. This is one of the most frequently tested facts in the subject.

Two vectors

Two vectors \(v_1, v_2\) are linearly dependent if and only if one is a scalar multiple of the other. Proof: if dependent, \(c_1 v_1 + c_2 v_2 = \mathbf{0}\) with not both zero. If \(c_1 \neq 0\), then \(v_1 = (-c_2/c_1) v_2\). If \(c_2 \neq 0\), then \(v_2 = (-c_1/c_2) v_1\). Conversely, if \(v_2 = \lambda v_1\), then \(\lambda v_1 + (-1) v_2 = \mathbf{0}\) is nontrivial. Geometrically in \(\mathbb{R}^2\) or \(\mathbb{R}^3\): two vectors are dependent exactly when they lie on the same line through the origin.

More vectors than dimensions

In \(\mathbb{R}^n\), any set of more than \(n\) vectors is linearly dependent. This is a consequence of the fact that a homogeneous system with more unknowns than equations always has a nontrivial solution (we'll prove this rigorously via rank in Chapter 5). For now, accept it as a powerful shortcut: in \(\mathbb{R}^3\), any four or more vectors are automatically dependent — no computation needed. Exams love this as a quick-check question.

Bases: independent spanning sets

We now have two properties a set of vectors can have: it can span a subspace (Chapter 1), and it can be independent. A set that does both deserves a name.

A basis of a vector space \(V\) (or of a subspace \(W \subseteq V\)) is a set of vectors that is:

  1. Linearly independent, and
  2. Spans \(V\) (or \(W\)).

Why is this combination special? Because it means the set is minimally sufficient: independent means no vector is redundant (you can't remove any without losing span), and spanning means no vector is missing (you can't add any without creating dependence). A basis is the "just right" set — no more, no less.

Uniqueness of representation

There is an equivalent characterization of bases that explains why they matter computationally. Let \(B = \{b_1, \dots, b_k\}\) be a basis of \(V\). Then every vector \(v \in V\) can be written as a linear combination of the \(b_i\) in exactly one way.

Proof: Existence follows from spanning. For uniqueness, suppose \(v = c_1 b_1 + \cdots + c_k b_k\) and also \(v = d_1 b_1 + \cdots + d_k b_k\). Subtract:

\[ \mathbf{0} = (c_1 - d_1) b_1 + \cdots + (c_k - d_k) b_k \]

Since the \(b_i\) are independent, every coefficient must be zero: \(c_i - d_i = 0\) for all \(i\), so \(c_i = d_i\). The representation is unique.

Conversely, if every \(v \in V\) has a unique representation as a linear combination of \(\{b_1, \dots, b_k\}\), then the set is a basis. Uniqueness for \(v = \mathbf{0}\) gives independence (the only representation of zero is the trivial one), and existence for all \(v\) gives spanning. So "basis" and "unique representation" are equivalent definitions. The coefficients \(c_1, \dots, c_k\) in the unique representation are called the coordinates of \(v\) with respect to the basis \(B\) — this is the foundation of coordinate systems in abstract vector spaces, and it's what makes computation possible in spaces like polynomials or function spaces where there are no "natural" coordinates.

Worked example: verifying a basis of \(\mathbb{R}^3\)

Show that \(B = \{(1, 0, 1),\ (0, 1, 1),\ (1, 1, 0)\}\) is a basis of \(\mathbb{R}^3\).

Step 1: Check independence. We already did this in the worked example above — the only solution to \(c_1 v_1 + c_2 v_2 + c_3 v_3 = \mathbf{0}\) is \(c_1 = c_2 = c_3 = 0\). ✓

Step 2: Check spanning. We need to show that for any \((a, b, c) \in \mathbb{R}^3\), there exist scalars \(x, y, z\) with

\[ x(1, 0, 1) + y(0, 1, 1) + z(1, 1, 0) = (a, b, c) \]

Expanding: \((x + z,\ y + z,\ x + y) = (a, b, c)\). This gives the system:

\[ \begin{cases} x + z = a \\ y + z = b \\ x + y = c \end{cases} \]

Solve: from (1), \(z = a - x\). From (2), \(y = b - z = b - a + x\). Substitute into (3): \(x + (b - a + x) = c\), so \(2x = c - b + a\), hence \(x = (a - b + c)/2\). Then \(z = a - x = (a + b - c)/2\) and \(y = b - z = (-a + b + c)/2\). Since \(a, b, c\) were arbitrary, a solution exists for every target vector. ✓

Conclusion: \(B\) is independent and spans \(\mathbb{R}^3\), so it is a basis. Notice we solved essentially the same system as in the independence check, but with a general right-hand side \((a,b,c)\) instead of \((0,0,0)\). This is not a coincidence — Chapter 4 will show that Gaussian elimination handles both tasks simultaneously.

Dimension: counting directions

Different bases of the same space can look very different. The standard basis \(\{e_1, e_2, e_3\}\) of \(\mathbb{R}^3\) looks nothing like the basis \(B\) from the previous example. But they share a crucial invariant: both have exactly three vectors. This is not accidental.

Theorem (Dimension is well-defined): If \(V\) has a finite basis, then every basis of \(V\) has the same number of elements.

The proof uses the replacement theorem (also called Steinitz exchange): if \(\{u_1, \dots, u_m\}\) spans \(V\) and \(\{v_1, \dots, v_n\}\) is independent, then \(n \leq m\). Applying this twice — once with the first basis as spanner and the second as independent set, then vice versa — gives \(n \leq m\) and \(m \leq n\), so \(m = n\). We won't prove the replacement theorem here (it requires careful induction and is covered in most rigorous treatments), but we will use its consequence freely.

The common number of elements in every basis of \(V\) is called the dimension of \(V\), written \(\dim V\). By convention, \(\dim \{\mathbf{0}\} = 0\) (the trivial subspace has the empty set as its basis).

Dimensions of familiar spaces

  • \(\dim \mathbb{R}^n = n\). The standard basis \(\{e_1, \dots, e_n\}\) has \(n\) elements.
  • \(\dim \mathcal{P}_n = n + 1\). The basis \(\{1, x, x^2, \dots, x^n\}\) has \(n + 1\) elements. Note: \(\mathcal{P}_n\) is polynomials of degree at most \(n\), so the constant polynomial counts.
  • \(\dim \mathbb{R}^{m \times n} = mn\). The matrices \(E_{ij}\) (with a 1 in position \((i,j)\) and zeros elsewhere) form a basis with \(mn\) elements.
  • The space of symmetric \(2 \times 2\) matrices (Example 6 of Chapter 1) has dimension 3: the basis \(\left\{ \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}, \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}, \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} \right\}\) has three elements, matching the three free parameters \(a, b, d\) we identified there.

Dimension as a diagnostic tool

Once you know \(\dim V = n\), checking whether a set of \(n\) vectors is a basis simplifies dramatically: in an \(n\)-dimensional space, a set of \(n\) vectors is a basis if and only if it is independent, if and only if it spans. You only need to verify one of the two properties; the other follows automatically from the dimension count. This is one of the most practically useful facts in the subject, and it's why computing dimension (via rank, in Chapter 5) is so central.

Common mistake: Students often assume that any set of \(n\) vectors in an \(n\)-dimensional space is a basis. This is false — the set must be either independent or spanning. For example, \(\{(1, 0), (2, 0)\}\) has two vectors in \(\mathbb{R}^2\) (dimension 2), but it is dependent (second is twice the first) and does not span (only reaches the x-axis). The dimension shortcut only applies when you've already verified one of the two basis properties.

Connecting back: dependence, span, and systems

Let us tie this chapter's concepts back to the language of Chapter 1 and forward to Chapters 4–5. Given vectors \(v_1, \dots, v_k\) in \(\mathbb{R}^n\), form the matrix \(A\) whose columns are these vectors. Then:

  • \(v_1, \dots, v_k\) are independent \(\iff\) \(\operatorname{Nul}(A) = \{\mathbf{0}\}\) \(\iff\) the system \(Ax = \mathbf{0}\) has only the trivial solution.
  • \(v_1, \dots, v_k\) are dependent \(\iff\) \(\operatorname{Nul}(A) \neq \{\mathbf{0}\}\) \(\iff\) the system \(Ax = \mathbf{0}\) has a nontrivial solution.
  • \(\operatorname{span}(v_1, \dots, v_k) = \operatorname{Col}(A)\), and \(\dim \operatorname{span}(v_1, \dots, v_k) = \dim \operatorname{Col}(A)\).
  • The rank of \(A\) (defined precisely in Chapter 5) equals \(\dim \operatorname{Col}(A)\), which equals the maximum number of independent columns, which equals the dimension of the span.

Every question about dependence, independence, span, and dimension reduces to a question about the null space and column space of a matrix — and those are exactly what Gaussian elimination (Chapter 4) and rank-nullity (Chapter 5) compute. This chapter gave you the language; the next two chapters give you the machinery.

Edge cases and boundary behavior

What happens when the set is empty? The empty set \(\varnothing\) is linearly independent (vacuously: there is no nontrivial relation because there are no vectors to form one). Its span is \(\{\mathbf{0}\}\) (the only linear combination of no vectors is the empty sum, which is defined to be \(\mathbf{0}\)). So \(\varnothing\) is a basis of the trivial subspace \(\{\mathbf{0}\}\), and \(\dim \{\mathbf{0}\} = 0\). This convention is consistent and necessary for theorems like rank-nullity to hold without special cases.

What about infinite-dimensional spaces? The space of all polynomials \(\mathcal{P}\) (no degree bound) has no finite basis — for any finite set of polynomials, there is a polynomial of higher degree not in their span. Such spaces are called infinite-dimensional. Everything in this chapter assumes finite-dimensionality; infinite-dimensional spaces require additional tools (Hamel bases, Zorn's lemma) beyond this book's scope. But the finite-dimensional intuition transfers: in functional analysis, "basis" gets generalized to Schauder bases, and dimension gets replaced by separability and other topological invariants.

Numerical sensitivity: In exact arithmetic, independence is a yes/no property. In floating-point computation, it becomes a matter of degree: vectors that are nearly dependent (e.g., \(v_2 = (1 + 10^{-15}) v_1\)) are technically independent but numerically indistinguishable from dependent ones. This is why numerical linear algebra uses the singular value decomposition (Chapter 11) rather than exact Gaussian elimination to assess "effective rank" — the SVD measures how close a set is to being dependent, not just whether it is.

What we built, and where it goes

  • Linear dependence means a nontrivial linear combination equals zero — equivalently, at least one vector is redundant (in the span of the others).
  • Linear independence means only the trivial combination gives zero — every vector contributes a new direction.
  • A basis is an independent spanning set — minimally sufficient, giving unique coordinates for every vector.
  • Dimension is the number of vectors in any basis — a well-defined invariant measuring the "number of directions" in a space.

Pencil-and-paper checkpoint: given any set of vectors, can you (a) write down the dependence/independence test as a homogeneous system, (b) solve it completely, (c) extract an explicit dependence relation if one exists, and (d) state the dimension of the span? If yes, you're ready for what comes next.
