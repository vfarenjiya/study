4. Systems of Linear Equations and Gaussian Elimination

Chapter 4 of 11 28 min read

The central question, made computational

Chapters 1 through 3 built the language: vector spaces, subspaces, span, dependence, matrix multiplication. But they left one question unanswered in practice: given a specific matrix \(A\) and vector \(b\), how do we actually determine whether \(Ax = b\) has a solution, and if so, how do we find all solutions? The theoretical answer — “check whether \(b \in \operatorname{Col}(A)\)” — is correct but not computable without further machinery.

This chapter provides that machinery: Gaussian elimination. The algorithm transforms \(A\) (or the augmented matrix \([A \mid b]\)) into a simpler form using three elementary row operations, each of which is equivalent to left-multiplication by an invertible matrix. Because these multiplications are invertible, the transformed system has exactly the same solution set as the original. From the simplified form, we can read off:

  • Whether the system is consistent (has any solution at all).
  • If consistent, a particular solution \(x_p\).
  • A basis for \(\operatorname{Nul}(A)\), giving the complete solution as \(x = x_p + x_h\) where \(x_h \in \operatorname{Nul}(A)\).
  • The pivot columns, which identify a basis for \(\operatorname{Col}(A)\) and determine the rank.

Every subsequent chapter depends on this one. Rank-nullity (Chapter 5), eigenvalues (Chapter 6), LU decomposition (Chapter 10), and SVD (Chapter 11) all either use elimination directly or build on the structural insights it reveals.

Elementary row operations as matrix multiplication

Gaussian elimination uses three operations on the rows of a matrix:

  1. Row swap: interchange rows \(i\) and \(j\).
  2. Row scaling: multiply row \(i\) by a nonzero scalar \(c\).
  3. Row replacement: add \(c\) times row \(j\) to row \(i\) (\(i \neq j\)).

The critical insight is that each operation is equivalent to left-multiplication by an elementary matrix. An elementary matrix is obtained by applying the corresponding operation to the identity matrix \(I\). For example, in \(\mathbb{R}^{3 \times 3}\):

  • Swapping rows 1 and 2: \(E_{\text{swap}} = \begin{pmatrix} 0 & 1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 1 \end{pmatrix}\)
  • Scaling row 2 by 3: \(E_{\text{scale}} = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 3 & 0 \\ 0 & 0 & 1 \end{pmatrix}\)
  • Adding 5 times row 1 to row 3: \(E_{\text{rep}} = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 5 & 0 & 1 \end{pmatrix}\)

Why does this work? Recall from Chapter 3 that left-multiplication by a matrix acts on rows: the \(i\)-th row of \(EA\) is a linear combination of the rows of \(A\), with coefficients given by the \(i\)-th row of \(E\). When \(E\) differs from \(I\) only in a structured way (one swapped pair, one scaled diagonal entry, one off-diagonal entry), the resulting row operation is exactly the one we intended. Verify with a concrete multiplication if this feels abstract — it is the foundation of everything that follows.

Elementary matrices are invertible

Each elementary matrix is invertible, and its inverse is the elementary matrix of the reverse operation:

  • Swap inverse: swap the same rows back. \(E_{\text{swap}}^{-1} = E_{\text{swap}}\) (swaps are self-inverse).
  • Scale inverse: scale the same row by \(1/c\). \(E_{\text{scale}}^{-1} = \operatorname{diag}(1, \dots, 1/c, \dots, 1)\).
  • Replacement inverse: subtract \(c\) times row \(j\) from row \(i\). \(E_{\text{rep}}^{-1}\) has \(-c\) in position \((i,j)\).

This invertibility is what makes elimination safe: if \(E_k \cdots E_2 E_1 A = U\), then \(A = E_1^{-1} E_2^{-1} \cdots E_k^{-1} U\), so no information is lost. The solution set of \(Ax = b\) is identical to the solution set of \(Ux = E_k \cdots E_1 b\), because each step is reversible.

Row echelon form and reduced row echelon form

Gaussian elimination produces a matrix in row echelon form (REF), characterized by:

  1. All zero rows (if any) are at the bottom.
  2. The first nonzero entry of each nonzero row (called a pivot) is strictly to the right of the pivot in the row above.
  3. All entries below a pivot are zero.

Reduced row echelon form (RREF) adds two more conditions:

  1. Every pivot equals 1.
  2. Every pivot is the only nonzero entry in its column.

RREF is unique for any given matrix — a deep fact we state without proof here (the proof uses the uniqueness of solutions to certain subsystems). REF is not unique (different pivot choices during elimination can yield different REFs), but the positions of the pivots are invariant. Those positions carry all the structural information we need.

Pivot columns and free columns

Columns containing pivots are pivot columns; the rest are free columns. In RREF, each free column is a linear combination of the pivot columns to its left, with the coefficients visible directly in the entries above the pivots. This is not accidental — it encodes the dependence relations among the original columns of \(A\). Specifically:

  • The pivot columns of \(A\) (not of RREF!) form a basis for \(\operatorname{Col}(A)\).
  • Each free column of \(A\) is a linear combination of the preceding pivot columns, with the same coefficients as in the RREF.

This is why we care about pivot positions: they tell us which original columns are independent and which are redundant.

Solving \(Ax = b\): the complete algorithm

We now assemble the full procedure for solving a linear system. Let \(A\) be \(m \times n\) and \(b \in \mathbb{R}^m\).

Step 1: Form the augmented matrix and reduce to RREF

Form \([A \mid b]\) and apply Gaussian elimination to obtain \([R \mid d]\), where \(R\) is the RREF of \(A\) and \(d\) is the transformed right-hand side. Track the operations implicitly (you don’t need to write down the elementary matrices unless you’re computing \(LU\) in Chapter 10).

Step 2: Check consistency

The system is consistent if and only if no row of \([R \mid d]\) has the form \([0 \ 0 \ \cdots \ 0 \mid c]\) with \(c \neq 0\). Such a row represents the equation \(0 = c\), which is impossible. If such a row exists, the system has no solution; stop here.

Why does this work? Row operations preserve the solution set (each is invertible left-multiplication). So \(Ax = b\) has a solution iff \(Rx = d\) has a solution. A row \([0 \cdots 0 \mid c]\) with \(c \neq 0\) makes \(Rx = d\) obviously unsolvable.

Step 3: Identify pivot and free variables

In \(R\), identify the pivot columns (say columns \(j_1, j_2, \dots, j_r\)) and the free columns. The variables corresponding to pivot columns are pivot variables; the rest are free variables. There are \(r\) pivot variables and \(n - r\) free variables, where \(r\) is the number of pivots (the rank of \(A\)).

Step 4: Write the general solution

Express each pivot variable in terms of the free variables by reading the equations from \(Rx = d\). Assign parameters \(t_1, \dots, t_{n-r}\) to the free variables. The general solution takes the form:

\[ x = x_p + t_1 v_1 + t_2 v_2 + \cdots + t_{n-r} v_{n-r} \]

where \(x_p\) is a particular solution (obtained by setting all free variables to zero) and \(v_1, \dots, v_{n-r}\) are vectors that span \(\operatorname{Nul}(A)\). Each \(v_i\) corresponds to setting one free variable to 1 and the others to 0, then solving for the pivot variables.

Worked example: complete solution of a \(3 \times 4\) system

Solve \(Ax = b\) where

\[ A = \begin{pmatrix} 1 & 2 & 3 & 4 \\ 2 & 4 & 6 & 8 \\ 1 & 2 & 4 & 6 \end{pmatrix}, \quad b = \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix} \]

Step 1: Augment and reduce.

\[ [A \mid b] = \left(\begin{array}{cccc|c} 1 & 2 & 3 & 4 & 1 \\ 2 & 4 & 6 & 8 & 2 \\ 1 & 2 & 4 & 6 & 3 \end{array}\right) \]

\(R_2 \leftarrow R_2 - 2R_1\): \(\left(\begin{array}{cccc|c} 1 & 2 & 3 & 4 & 1 \\ 0 & 0 & 0 & 0 & 0 \\ 1 & 2 & 4 & 6 & 3 \end{array}\right)\)

\(R_3 \leftarrow R_3 - R_1\): \(\left(\begin{array}{cccc|c} 1 & 2 & 3 & 4 & 1 \\ 0 & 0 & 0 & 0 & 0 \\ 0 & 0 & 1 & 2 & 2 \end{array}\right)\)

Swap \(R_2 \leftrightarrow R_3\): \(\left(\begin{array}{cccc|c} 1 & 2 & 3 & 4 & 1 \\ 0 & 0 & 1 & 2 & 2 \\ 0 & 0 & 0 & 0 & 0 \end{array}\right)\)

\(R_1 \leftarrow R_1 - 3R_2\): \(\left(\begin{array}{cccc|c} 1 & 2 & 0 & -2 & -5 \\ 0 & 0 & 1 & 2 & 2 \\ 0 & 0 & 0 & 0 & 0 \end{array}\right)\)

This is RREF. Pivots are in columns 1 and 3; free columns are 2 and 4.

Step 2: Consistency. No row of the form \([0 \ 0 \ 0 \ 0 \mid c]\) with \(c \neq 0\). System is consistent.

Step 3: Variables. Pivot variables: \(x_1, x_3\). Free variables: \(x_2 = s\), \(x_4 = t\).

Step 4: General solution. From RREF:

\[ \begin{cases} x_1 + 2x_2 - 2x_4 = -5 \\ x_3 + 2x_4 = 2 \end{cases} \implies \begin{cases} x_1 = -5 - 2s + 2t \\ x_3 = 2 - 2t \end{cases} \]

In vector form:

\[ x = \begin{pmatrix} -5 \\ 0 \\ 2 \\ 0 \end{pmatrix} + s \begin{pmatrix} -2 \\ 1 \\ 0 \\ 0 \end{pmatrix} + t \begin{pmatrix} 2 \\ 0 \\ -2 \\ 1 \end{pmatrix} \]

The first vector is \(x_p\) (set \(s = t = 0\)). The other two span \(\operatorname{Nul}(A)\). Verify: \(A \begin{pmatrix} -2 \\ 1 \\ 0 \\ 0 \end{pmatrix} = \begin{pmatrix} -2+2 \\ -4+4 \\ -2+2 \end{pmatrix} = \mathbf{0}\) ✓, and similarly for the second null-space vector. The solution set is an affine plane in \(\mathbb{R}^4\): a translate of the 2-dimensional null space by \(x_p\).

The homogeneous case: finding a null-space basis

When \(b = \mathbf{0}\), the system is always consistent (zero is always a solution), and \(x_p = \mathbf{0}\). The general solution is simply \(x = t_1 v_1 + \cdots + t_{n-r} v_{n-r}\), where the \(v_i\) are constructed exactly as above: for each free variable, set it to 1 and the others to 0, solve for the pivot variables, and record the resulting vector. These vectors are:

  • In \(\operatorname{Nul}(A)\) by construction.
  • Linearly independent (each has a 1 in a distinct free-variable position where all others have 0).
  • Spanning \(\operatorname{Nul}(A)\) (every null-space vector arises from some choice of free variables).

So they form a basis for \(\operatorname{Nul}(A)\), and \(\dim \operatorname{Nul}(A) = n - r\). This is half of the rank-nullity theorem; Chapter 5 completes it by showing \(\dim \operatorname{Col}(A) = r\).

Worked example: null-space basis from RREF

Using the RREF from the previous example (with \(b = \mathbf{0}\)): pivots in columns 1, 3; free in columns 2, 4. Set \(x_2 = 1, x_4 = 0\): then \(x_1 = -2\), \(x_3 = 0\) → \(v_1 = (-2, 1, 0, 0)^\top\). Set \(x_2 = 0, x_4 = 1\): then \(x_1 = 2\), \(x_3 = -2\) → \(v_2 = (2, 0, -2, 1)^\top\). Basis: \(\{v_1, v_2\}\). Dimension of null space: \(4 - 2 = 2\). ✓

Consistency revisited: when does \(Ax = b\) have a solution?

We stated the consistency test above (no contradictory row in RREF). Here is the geometric interpretation, connecting back to Chapter 1: \(Ax = b\) is consistent if and only if \(b \in \operatorname{Col}(A)\). The elimination test is the computational version of this membership check. When elimination produces a row \([0 \cdots 0 \mid c]\) with \(c \neq 0\), it has discovered that \(b\) has a component orthogonal to \(\operatorname{Col}(A)\) — specifically, the corresponding row of the elimination matrix gives a vector \(y\) such that \(y^\top A = \mathbf{0}\) but \(y^\top b = c \neq 0\). This is the Fredholm alternative in finite dimensions: either \(Ax = b\) has a solution, or there exists \(y\) with \(A^\top y = \mathbf{0}\) and \(y^\top b \neq 0\), but not both. We revisit this in Chapter 7 (orthogonality) and Chapter 8 (projections).

Rank from elimination

The rank of \(A\) is the number of pivots in its RREF (equivalently, in any REF). From the worked example, \(\operatorname{rank}(A) = 2\). Key facts (proved formally in Chapter 5, but visible now):

  • \(\operatorname{rank}(A) = \dim \operatorname{Col}(A)\): the pivot columns of \(A\) form a basis for the column space.
  • \(\operatorname{rank}(A) = \dim \operatorname{Row}(A)\): row operations preserve the row space, and the nonzero rows of RREF are a basis for it.
  • \(\operatorname{rank}(A) = \operatorname{rank}(A^\top)\): column rank equals row rank. (This is non-obvious from the definition; Chapter 5 proves it via rank-nullity.)

Important: The pivot columns of RREF are standard basis vectors and do not form a basis for \(\operatorname{Col}(A)\). To get a column-space basis, take the corresponding columns of the original matrix \(A\). In our example, pivots are in columns 1 and 3 of RREF, so \(\{(1,2,1)^\top, (3,6,4)^\top\}\) is a basis for \(\operatorname{Col}(A)\). Never extract the column-space basis from RREF itself.

Edge cases and common mistakes

Mistake: extracting column-space basis from RREF. As noted above, the pivot columns of RREF are \(\{e_1, e_2, \dots\}\) and span a coordinate subspace, not \(\operatorname{Col}(A)\). Always go back to the original \(A\). This is the single most common error in applied linear algebra exams.

Mistake: confusing pivot variables with pivot columns. Pivot variables correspond to pivot columns, but the terms refer to different objects (variables vs. matrix columns). Be precise: “column 3 is a pivot column” and “\(x_3\) is a pivot variable.”

Edge case: no free variables. If every column is a pivot column (\(r = n\)), then \(\operatorname{Nul}(A) = \{\mathbf{0}\}\), and the system has at most one solution. If also consistent, the solution is unique. This is the case of full column rank.

Edge case: no pivot variables. If \(A = \mathbf{0}\), then \(r = 0\), all variables are free, and \(\operatorname{Nul}(A) = \mathbb{R}^n\). The system \(0x = b\) is consistent only if \(b = \mathbf{0}\), in which case every \(x \in \mathbb{R}^n\) is a solution.

Numerical caution: In exact arithmetic, a pivot is either zero or nonzero. In floating-point, tiny nonzero values may be numerical noise rather than true pivots. Practical implementations use pivoting (partial or complete) to choose the largest available entry as pivot, improving numerical stability. Chapter 10 (LU decomposition) formalizes this; Chapter 11 (SVD) provides the gold standard for rank determination in noisy settings.

Underdetermined vs. overdetermined. “More unknowns than equations” (\(n > m\)) guarantees either no solution or infinitely many (never a unique solution, since \(r \leq m < n\) implies at least \(n - r \geq 1\) free variables). “More equations than unknowns” (\(m > n\)) may be inconsistent or have a unique solution, but never infinitely many (unless rows are dependent). These are consequences of \(r \leq \min(m, n)\), not independent rules.

What we built, and where it goes

  • Gaussian elimination reduces any matrix to RREF via invertible row operations, preserving the solution set of \(Ax = b\).
  • Consistency is determined by the absence of contradictory rows in the augmented RREF.
  • The complete solution is \(x = x_p + x_h\), where \(x_p\) is particular and \(x_h \in \operatorname{Nul}(A)\) is a linear combination of null-space basis vectors extracted from free variables.
  • Rank is the number of pivots; pivot columns of \(A\) (not RREF) give a column-space basis.
  • Every row operation is left-multiplication by an invertible elementary matrix — the bridge to LU decomposition in Chapter 10.

Pencil-and-paper checkpoint: given a \(3 \times 5\) matrix, can you reduce it to RREF by hand, identify pivot/free columns, write the general solution of \(Ax = b\) for a given \(b\), and extract bases for both \(\operatorname{Col}(A)\) and \(\operatorname{Nul}(A)\)? Can you explain why the pivot columns of RREF are not a basis for \(\operatorname{Col}(A)\)? If yes, you have internalized the algorithm.

Chapter 5 extracts the theoretical payload from this computational machinery: determinants (a scalar test for invertibility), rank (formalized and proven equal for rows and columns), and the rank-nullity theorem (the dimension equation tying everything together). Chapter 6 then uses elimination to compute eigenvalues via the characteristic polynomial. Everything flows from the algorithm built here.
