5. Determinants, Rank, and Nullity

Chapter 5 of 11 27 min read

Three numbers that tell the whole story

Chapter 4 gave us an algorithm: reduce to RREF, read off pivots, solve the system. But algorithms answer specific questions (“does this particular \(Ax = b\) have a solution?”). This chapter asks structural questions that apply to any matrix, independent of any specific right-hand side:

  • Is \(A\) invertible? (Can we solve \(Ax = b\) for every \(b\)?)
  • How many independent directions does \(A\) preserve? (What is the dimension of its column space?)
  • How many directions does \(A\) collapse? (What is the dimension of its null space?)

Three invariants answer these questions completely: the determinant, the rank, and the nullity. The determinant is a single scalar that tests invertibility. Rank and nullity are nonnegative integers whose sum equals the number of columns — the rank-nullity theorem, the single most important structural result in linear algebra. This chapter derives all three from first principles, connects them to the RREF machinery of Chapter 4, and proves their fundamental relationships.

The determinant: defined by what it does

The determinant is often introduced as a formula (cofactor expansion, Leibniz sum), but formulas obscure why the determinant exists. Instead, we define it by the properties that make it useful, then show those properties determine it uniquely.

Three axioms

A function \(D : \mathbb{R}^{n \times n} \to \mathbb{R}\) is called a determinant function if it satisfies:

  1. Multilinearity in rows: \(D\) is linear in each row when the other rows are held fixed. That is, for any row index \(i\), scalars \(a, b\), and row vectors \(r, s\): \[ D(\dots, ar + bs, \dots) = a\,D(\dots, r, \dots) + b\,D(\dots, s, \dots) \] where the ellipses indicate identical rows in all other positions.
  2. Alternating: Swapping two rows changes the sign: \(D(\dots, r_i, \dots, r_j, \dots) = -D(\dots, r_j, \dots, r_i, \dots)\). Equivalently (and this is worth verifying), if two rows are identical, \(D = 0\). (Proof: swap the identical rows; the value must both stay the same and flip sign, so it must be zero.)
  3. Normalization: \(D(I_n) = 1\).

These three axioms capture exactly what we want a “volume-like” invariant to do: scale linearly when you stretch one direction, flip sign when you reverse orientation (swap), and assign unit volume to the unit cube. Everything else follows.

Uniqueness: why there is only one determinant

Theorem: There is exactly one function satisfying the three axioms above.

Proof sketch (constructive): Apply Gaussian elimination to \(A\). Each row operation affects \(D\) in a known way: row replacement (adding a multiple of one row to another) doesn’t change \(D\) (multilinearity + alternating: \(D(\dots, r_i + cr_j, \dots) = D(\dots, r_i, \dots) + c\,D(\dots, r_j, \dots)\), and the second term is zero because rows \(i\) and \(j\) would be identical after factoring). Row scaling by \(c\) multiplies \(D\) by \(c\). Row swap multiplies \(D\) by \(-1\). So if elimination reduces \(A\) to RREF \(R\) via operations with cumulative scaling factor \(\alpha\) and \(s\) swaps, then \(D(A) = \alpha^{-1} (-1)^s D(R)\). But \(R\) is either \(I_n\) (if \(A\) is invertible) or has a zero row (if not). If \(R\) has a zero row, multilinearity gives \(D(R) = 0\). If \(R = I_n\), normalization gives \(D(R) = 1\). So \(D(A)\) is completely determined by the elimination process and the three axioms. Since elimination always terminates, \(D\) is uniquely defined.

This proof also gives us a computation method: reduce to upper triangular form using row operations, tracking the scaling factors and swaps, then multiply the diagonal entries. This is far more efficient than cofactor expansion for large matrices.

Consequences derived from the axioms

From the three axioms alone, we can derive every property of the determinant without ever writing a formula:

  • \(\det(AB) = \det(A)\det(B)\): Fix \(B\) and consider \(f(A) = \det(AB)/\det(B)\) (for \(\det(B) \neq 0\)). Check that \(f\) satisfies all three axioms as a function of \(A\). By uniqueness, \(f(A) = \det(A)\). Rearrange. (When \(\det(B) = 0\), \(B\) is singular, so \(AB\) is singular, and both sides are zero.)
  • \(\det(A^\top) = \det(A)\): The axioms are stated for rows, but since row operations on \(A\) correspond to column operations on \(A^\top\), and the axioms are symmetric between rows and columns (the proof of uniqueness works identically for columns), the determinant is also the unique alternating multilinear function on columns normalized on \(I\). Hence \(\det(A^\top) = \det(A)\).
  • \(A\) is invertible \(\iff \det(A) \neq 0\): If \(A\) is invertible, \(AA^{-1} = I\), so \(\det(A)\det(A^{-1}) = \det(I) = 1\), hence \(\det(A) \neq 0\). Conversely, if \(\det(A) \neq 0\), elimination produces no zero row, so RREF is \(I\), so \(A\) is invertible (Chapter 4).
  • \(\det(A^{-1}) = 1/\det(A)\): Immediate from \(\det(A)\det(A^{-1}) = \det(I) = 1\).
  • \(\det(cA) = c^n \det(A)\) for \(n \times n\) matrices: Scaling \(A\) by \(c\) scales each of the \(n\) rows by \(c\); multilinearity pulls out one factor of \(c\) per row.

Notice: we never wrote a single explicit formula. Every property followed from the axioms and uniqueness. This is the power of defining objects by what they do rather than how they’re computed.

Worked example: computing a \(3 \times 3\) determinant via elimination

Compute \(\det(A)\) for \(A = \begin{pmatrix} 2 & 1 & 3 \\ 4 & 3 & 7 \\ 6 & 5 & 11 \end{pmatrix}\).

Step 1: Eliminate below pivot in column 1. \(R_2 \leftarrow R_2 - 2R_1\): new \(R_2 = (0, 1, 1)\). \(R_3 \leftarrow R_3 - 3R_1\): new \(R_3 = (0, 2, 2)\). These are row replacements, which don’t change the determinant.

\[ A' = \begin{pmatrix} 2 & 1 & 3 \\ 0 & 1 & 1 \\ 0 & 2 & 2 \end{pmatrix}, \quad \det(A') = \det(A) \]

Step 2: Eliminate below pivot in column 2. \(R_3 \leftarrow R_3 - 2R_2\): new \(R_3 = (0, 0, 0)\). Again a row replacement.

\[ U = \begin{pmatrix} 2 & 1 & 3 \\ 0 & 1 & 1 \\ 0 & 0 & 0 \end{pmatrix}, \quad \det(U) = \det(A) \]

Step 3: Read off. \(U\) is upper triangular with a zero on the diagonal. By multilinearity (expand along the zero row), \(\det(U) = 0\). Therefore \(\det(A) = 0\).

Verification via dependence: Notice \(R_3 = R_1 + R_2\) in the original matrix: \((6,5,11) = (2,1,3) + (4,3,7)\). Dependent rows → zero determinant. ✓ This confirms our computation and illustrates the connection: \(\det(A) = 0\) iff the rows (equivalently, columns) are linearly dependent.

Cofactor expansion: useful for theory, expensive for computation

For theoretical proofs (e.g., showing \(\det\) is a polynomial in the entries), the Laplace expansion along row \(i\) is indispensable:

\[ \det(A) = \sum_{j=1}^{n} (-1)^{i+j} a_{ij} \det(M_{ij}) \]

where \(M_{ij}\) is the \((n-1) \times (n-1)\) submatrix obtained by deleting row \(i\) and column \(j\). This is a recursive definition, reducing an \(n \times n\) determinant to \(n\) determinants of size \((n-1)\). For hand computation of small matrices (\(2 \times 2\), \(3 \times 3\)), it’s fine. For \(n \geq 4\), it requires \(O(n!)\) operations — use elimination instead. But keep cofactor expansion in your toolkit for proofs and for understanding the adjugate formula \(A^{-1} = \frac{1}{\det(A)} \operatorname{adj}(A)\).

Rank: the dimension of the image

In Chapter 4, we defined the rank of \(A\) as the number of pivots in its RREF. Now we formalize this and prove it equals several other natural quantities.

Equivalent definitions of rank

For an \(m \times n\) matrix \(A\), the following are all equal:

  1. Column rank: \(\dim \operatorname{Col}(A)\) — the dimension of the span of the columns.
  2. Row rank: \(\dim \operatorname{Row}(A)\) — the dimension of the span of the rows.
  3. Pivot rank: the number of pivot positions in the RREF of \(A\).
  4. Determinantal rank: the size of the largest square submatrix of \(A\) with nonzero determinant.

We prove the equivalences step by step.

Column rank = pivot rank

From Chapter 4: the pivot columns of \(A\) (not of RREF!) form a basis for \(\operatorname{Col}(A)\). There are exactly as many pivot columns as there are pivots. So \(\dim \operatorname{Col}(A) = \text{(number of pivots)}\).

Row rank = pivot rank

Elementary row operations preserve the row space (each new row is a linear combination of old rows, and the operations are invertible). The nonzero rows of RREF are linearly independent (each has a leading 1 in a distinct column where all other rows have 0). So the nonzero rows of RREF form a basis for \(\operatorname{Row}(A)\), and there are exactly as many as there are pivots.

Column rank = row rank

Both equal the pivot rank, so they equal each other. This is remarkable: a priori, the column space lives in \(\mathbb{R}^m\) and the row space in \(\mathbb{R}^n\) — completely different ambient spaces. Yet their dimensions are always equal. We denote this common value simply as \(\operatorname{rank}(A)\).

Determinantal rank = pivot rank

If \(A\) has \(r\) pivots, then RREF has an \(r \times r\) identity block in the top-left (after permutation), so \(A\) has an \(r \times r\) submatrix with nonzero determinant (the corresponding submatrix of \(A\) is invertible because elimination restricted to those rows/columns is invertible). Conversely, if \(A\) has a \(k \times k\) invertible submatrix, then those \(k\) rows are independent and those \(k\) columns are independent, so rank \(\geq k\). The largest such \(k\) equals the rank.

Worked example: computing rank three ways

Let \(A = \begin{pmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \\ 1 & 3 & 5 \end{pmatrix}\).

Method 1 (RREF): \(R_2 \leftarrow R_2 - 2R_1 = (0,0,0)\); \(R_3 \leftarrow R_3 - R_1 = (0,1,2)\). Swap \(R_2 \leftrightarrow R_3\): \(\begin{pmatrix} 1 & 2 & 3 \\ 0 & 1 & 2 \\ 0 & 0 & 0 \end{pmatrix}\). Two pivots → rank = 2.

Method 2 (column inspection): Column 2 = \(2 \times\) column 1, so columns are dependent. Columns 1 and 3: are they independent? \(c_1(1,2,1) + c_3(3,6,5) = 0\) gives \(c_1 + 3c_3 = 0\), \(2c_1 + 6c_3 = 0\), \(c_1 + 5c_3 = 0\). First and third: subtracting gives \(2c_3 = 0\) → \(c_3 = 0\) → \(c_1 = 0\). Independent. So column space has dimension 2 → rank = 2. ✓

Method 3 (determinantal): \(\det(A) = 0\) (rows dependent: \(R_2 = 2R_1\)). Check \(2 \times 2\) submatrices: top-left \(\begin{pmatrix} 1 & 2 \\ 2 & 4 \end{pmatrix}\) has det 0. But \(\begin{pmatrix} 1 & 3 \\ 1 & 5 \end{pmatrix}\) has det \(5 - 3 = 2 \neq 0\). Largest invertible submatrix is \(2 \times 2\) → rank = 2. ✓

All three methods agree. In practice, RREF is fastest for hand computation; determinantal rank is useful for theoretical bounds; column/row inspection works for small structured matrices.

Nullity and the rank-nullity theorem

The nullity of \(A\) is \(\dim \operatorname{Nul}(A)\). From Chapter 4, we know how to compute it: reduce to RREF, count the free variables. If \(A\) is \(m \times n\) with rank \(r\), then there are \(n - r\) free variables, and the null-space basis vectors constructed from them are linearly independent and spanning. So:

\[ \operatorname{nullity}(A) = n - r = n - \operatorname{rank}(A) \]

Rearranging gives the central theorem:

\[ \boxed{\operatorname{rank}(A) + \operatorname{nullity}(A) = n} \]

where \(n\) is the number of columns of \(A\). This is the rank-nullity theorem (also called the dimension theorem).

Why this theorem matters

Rank-nullity says that the dimensions of the image and kernel of a linear map always add up to the dimension of the domain. It is the linear-algebraic version of the pigeonhole principle: if you map an \(n\)-dimensional space into some target, the amount of information preserved (rank) plus the amount lost (nullity) must equal \(n\). Consequences include:

  • An \(n \times n\) matrix is invertible iff its nullity is 0 iff its rank is \(n\).
  • If \(m < n\) (more columns than rows), then \(\operatorname{rank}(A) \leq m < n\), so \(\operatorname{nullity}(A) \geq n - m > 0\): wide matrices always have nontrivial null spaces. Systems \(Ax = b\) with \(m < n\) are never uniquely solvable.
  • If \(m > n\) (more rows than columns), then \(\operatorname{rank}(A) \leq n\), so \(\operatorname{nullity}(A) \geq 0\) (always true), but \(\operatorname{Col}(A)\) is a proper subspace of \(\mathbb{R}^m\) whenever \(\operatorname{rank}(A) < m\): tall matrices cannot be surjective. Systems \(Ax = b\) may be inconsistent.
  • For a linear map \(T : V \to W\) between finite-dimensional spaces, \(\dim V = \dim \ker T + \dim \operatorname{im} T\). The matrix version is the special case \(V = \mathbb{R}^n\), \(W = \mathbb{R}^m\).

Worked example: rank-nullity in action

Let \(A = \begin{pmatrix} 1 & 2 & 3 & 4 \\ 2 & 4 & 6 & 8 \\ 1 & 2 & 4 & 6 \end{pmatrix}\) (the same matrix from Chapter 4’s worked example). From Chapter 4, RREF has pivots in columns 1 and 3, so \(\operatorname{rank}(A) = 2\). The matrix has \(n = 4\) columns, so rank-nullity predicts \(\operatorname{nullity}(A) = 4 - 2 = 2\). Indeed, Chapter 4 found a null-space basis with two vectors: \(\{(-2,1,0,0)^\top, (2,0,-2,1)^\top\}\). Dimension 2. ✓

Follow-up question: What is \(\dim \operatorname{Col}(A)\)? Answer: 2 (equal to rank). What is \(\dim \operatorname{Row}(A)\)? Also 2. What ambient space does each live in? \(\operatorname{Col}(A) \subseteq \mathbb{R}^3\), \(\operatorname{Row}(A) \subseteq \mathbb{R}^4\). Different ambient spaces, same dimension — rank-nullity doesn’t say anything about the ambient spaces, only about the domain dimension \(n = 4\).

Properties of rank under operations

Rank behaves predictably under common matrix operations. These inequalities are used constantly in later chapters (especially Chapters 6, 10, 11):

  • \(\operatorname{rank}(AB) \leq \min(\operatorname{rank}(A), \operatorname{rank}(B))\): \(\operatorname{Col}(AB) \subseteq \operatorname{Col}(A)\) (every column of \(AB\) is \(A\) times something), so \(\operatorname{rank}(AB) \leq \operatorname{rank}(A)\). Also \(\operatorname{rank}(AB) = \operatorname{rank}((AB)^\top) = \operatorname{rank}(B^\top A^\top) \leq \operatorname{rank}(B^\top) = \operatorname{rank}(B)\).
  • \(\operatorname{rank}(A + B) \leq \operatorname{rank}(A) + \operatorname{rank}(B)\): \(\operatorname{Col}(A + B) \subseteq \operatorname{Col}(A) + \operatorname{Col}(B)\), and \(\dim(U + V) \leq \dim U + \dim V\).
  • Sylvester’s inequality: \(\operatorname{rank}(A) + \operatorname{rank}(B) - n \leq \operatorname{rank}(AB)\) for \(A\) (\(m \times n\)) and \(B\) (\(n \times p\)). This lower bound complements the upper bound above.
  • Rank is invariant under multiplication by invertible matrices: If \(P\) and \(Q\) are invertible, \(\operatorname{rank}(PAQ) = \operatorname{rank}(A)\). Multiplication by invertible matrices corresponds to change of basis in domain and codomain; rank is a basis-independent property.

Edge cases and common mistakes

Mistake: confusing rank with the number of nonzero rows in REF (not RREF). In REF (non-reduced), a row may be nonzero but still dependent on earlier rows. Only RREF guarantees that nonzero rows are independent. Always reduce fully, or verify independence explicitly.

Mistake: assuming \(\det(A + B) = \det(A) + \det(B)\). The determinant is multilinear in rows, not additive over matrices. For example, \(\det(I + I) = \det(2I) = 2^n \neq 2 = \det(I) + \det(I)\) for \(n \geq 2\). Determinant is multiplicative (\(\det(AB) = \det(A)\det(B)\)), not additive.

Edge case: rank of the zero matrix. \(\operatorname{rank}(\mathbf{0}_{m \times n}) = 0\), \(\operatorname{nullity} = n\). Rank-nullity: \(0 + n = n\). ✓ The zero matrix collapses everything.

Edge case: full-rank matrices. An \(m \times n\) matrix has full column rank if \(\operatorname{rank}(A) = n\) (requires \(m \geq n\)); full row rank if \(\operatorname{rank}(A) = m\) (requires \(n \geq m\)); full rank if square and \(\operatorname{rank}(A) = n = m\) (invertible). Full column rank ⟺ columns independent ⟺ \(Ax = \mathbf{0}\) has only trivial solution ⟺ \(A^\top A\) is invertible. Full row rank ⟺ rows independent ⟺ \(Ax = b\) is consistent for every \(b\) ⟺ \(AA^\top\) is invertible. These characterizations return in Chapters 7–8 (least squares, projections).

Numerical caution: In floating-point arithmetic, rank determination via RREF or determinant is unreliable. Tiny perturbations can turn a rank-deficient matrix into a full-rank one (or vice versa). The numerically stable approach uses the SVD (Chapter 11): the numerical rank is the number of singular values exceeding a tolerance. Never trust a determinant near machine epsilon as evidence of singularity or nonsingularity.

What we built, and where it goes

  • The determinant is the unique alternating multilinear function on rows normalized on \(I\); it tests invertibility and satisfies \(\det(AB) = \det(A)\det(B)\).
  • Rank is the common value of column rank, row rank, pivot rank, and determinantal rank — the dimension of the image of \(A\).
  • Nullity is the dimension of the kernel of \(A\), and \(\operatorname{rank}(A) + \operatorname{nullity}(A) = n\) (rank-nullity theorem).
  • Rank inequalities govern how rank behaves under products, sums, and changes of basis.
