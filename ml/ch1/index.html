1. The Learning Problem & Simple Linear Regression

Chapter 1 of 14 35 min read

What does it mean to learn from data?

Imagine you are a doctor. You have records of 200 patients: their age, blood pressure, cholesterol, and whether they developed heart disease within five years. A new patient walks in with age 54, blood pressure 140, cholesterol 220. You need to answer: will this patient develop heart disease?

You have never seen this exact combination of numbers before. You cannot look it up. All you have are those 200 past records. The question machine learning asks is: can we write a rule — a function — that takes the new patient's numbers and outputs a useful prediction, learned entirely from the 200 examples?

Formally, we call the inputs features and collect them into a vector \(x\). The output we want to predict is the target \(y\). We observe \(n\) training pairs:

\[\{(x_1, y_1),\; (x_2, y_2),\; \ldots,\; (x_n, y_n)\}\]

Our goal is to find a function \(f\) such that \(f(x)\) is a good prediction of \(y\) for new, unseen inputs. The function \(f\) is learned from the training data — that is the "learning" in machine learning.

But what does "good prediction" mean? And what kind of function should \(f\) be? These two questions define the entire landscape of supervised learning, and they lead directly to the split between regression and classification.

Regression vs. Classification

Look at the target \(y\). What kind of quantity is it?

If \(y\) is a continuous number — a house price, a temperature, a patient's blood sugar level — then we are doing regression. The function \(f(x)\) must output a real number, and we measure how wrong it is by asking "how far off was the number?"

If \(y\) is a discrete label — "spam" or "not spam," "cat" or "dog," "disease" or "no disease" — then we are doing classification. The function \(f(x)\) must output a label (or a probability over labels), and we measure how wrong it is by asking "did it pick the right category?"

This distinction is not cosmetic. It changes which loss functions make sense, which algorithms are natural, and which mathematical tools we reach for. Regression leans on calculus and linear algebra over real-valued outputs. Classification leans on probability, thresholds, and decision boundaries.

In this chapter we begin with regression — specifically, the simplest possible regression problem: predicting \(y\) from a single input \(x\) using a straight line. This is simple linear regression, and it is the foundation on which nearly every supervised method in this book is built.

Simple Linear Regression: the question

Suppose you have \(n\) data points, each with one input \(x_i\) and one output \(y_i\). You suspect the relationship is roughly linear: bigger \(x\) tends to mean bigger \(y\), or smaller \(y\), in a straight-line fashion. You want to find the "best" straight line through the scatter of points.

A straight line is described by two numbers — an intercept \(\beta_0\) and a slope \(\beta_1\):

\[\hat{y} = \beta_0 + \beta_1 x\]

The hat on \(\hat{y}\) reminds us this is a prediction, not the true observed \(y\). For each data point \(x_i\), our line predicts \(\hat{y}_i = \beta_0 + \beta_1 x_i\). The true value is \(y_i\). The difference is the residual:

\[e_i = y_i - \hat{y}_i = y_i - (\beta_0 + \beta_1 x_i)\]

Now the question becomes precise: which values of \(\beta_0\) and \(\beta_1\) make the residuals "as small as possible" overall?

But "as small as possible" still needs a definition. We have \(n\) residuals. How do we combine them into a single number to minimize?

Why squared error? A Socratic detour

A first instinct might be: just add up all the residuals and make that sum small. Let's see why that fails. Consider three points where the residuals are \(+3\), \(-3\), and \(+1\). Their sum is \(+1\). But another line gives residuals \(+1\), \(+1\), \(-1\), whose sum is also \(+1\). Are these lines equally good? Clearly not — the first line has two errors of magnitude 3, while the second has errors of magnitude 1. The sum of raw residuals hides the size of individual errors because positives and negatives cancel.

What if we take absolute values? Minimize \(\sum |e_i|\)? This is actually a legitimate approach (it leads to least absolute deviations regression), but it has a practical drawback: the absolute value function has a sharp corner at zero, which makes calculus harder. Derivatives don't exist at the corner, so we can't just set a derivative to zero and solve cleanly.

What if we square each residual before summing? The squared loss \((y_i - \hat{y}_i)^2\) has three beautiful properties:

  • It is always non-negative, so positives and negatives don't cancel.
  • It penalizes large errors more than small ones (an error of 3 costs 9, not 3), which encourages the line not to leave any point badly behind.
  • It is a smooth, differentiable function of \(\beta_0\) and \(\beta_1\), so we can use calculus to find the minimum exactly.

So we define the Residual Sum of Squares (RSS) as our objective:

\[\text{RSS}(\beta_0, \beta_1) = \sum_{i=1}^{n} (y_i - \beta_0 - \beta_1 x_i)^2\]

Our goal: find \(\beta_0\) and \(\beta_1\) that minimize RSS. This is the Ordinary Least Squares (OLS) criterion.

Deriving the OLS estimators

We minimize RSS by taking partial derivatives with respect to \(\beta_0\) and \(\beta_1\), setting both to zero, and solving the resulting system. RSS is a quadratic function of \((\beta_0, \beta_1)\) — a bowl-shaped surface — so the critical point we find will be the global minimum.

Step 1: Partial derivative with respect to \(\beta_0\)

We differentiate RSS treating \(\beta_1\) as a constant. Each term in the sum is \((y_i - \beta_0 - \beta_1 x_i)^2\). By the chain rule, the derivative of \((u)^2\) with respect to \(\beta_0\), where \(u = y_i - \beta_0 - \beta_1 x_i\), is \(2u \cdot \frac{\partial u}{\partial \beta_0} = 2(y_i - \beta_0 - \beta_1 x_i)(-1)\). So:

\[\frac{\partial \text{RSS}}{\partial \beta_0} = \sum_{i=1}^{n} 2(y_i - \beta_0 - \beta_1 x_i)(-1) = -2\sum_{i=1}^{n}(y_i - \beta_0 - \beta_1 x_i)\]

Setting this equal to zero and dividing both sides by \(-2\):

\[\sum_{i=1}^{n}(y_i - \beta_0 - \beta_1 x_i) = 0\]

Distributing the sum:

\[\sum_{i=1}^{n} y_i - n\beta_0 - \beta_1 \sum_{i=1}^{n} x_i = 0\]

Solving for \(\beta_0\):

\[n\beta_0 = \sum_{i=1}^{n} y_i - \beta_1 \sum_{i=1}^{n} x_i\] \[\beta_0 = \frac{1}{n}\sum_{i=1}^{n} y_i - \beta_1 \cdot \frac{1}{n}\sum_{i=1}^{n} x_i = \bar{y} - \beta_1 \bar{x}\]

where \(\bar{y} = \frac{1}{n}\sum y_i\) and \(\bar{x} = \frac{1}{n}\sum x_i\) are the sample means. This is our first key result:

\[\boxed{\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}}\]

This tells us something geometric: the fitted line always passes through the point \((\bar{x}, \bar{y})\), the centroid of the data. No matter what the slope is, the line pivots through the center.

Step 2: Partial derivative with respect to \(\beta_1\)

Now differentiate RSS with respect to \(\beta_1\), treating \(\beta_0\) as constant. The chain rule gives:

\[\frac{\partial \text{RSS}}{\partial \beta_1} = \sum_{i=1}^{n} 2(y_i - \beta_0 - \beta_1 x_i)(-x_i) = -2\sum_{i=1}^{n} x_i(y_i - \beta_0 - \beta_1 x_i)\]

Setting equal to zero and dividing by \(-2\):

\[\sum_{i=1}^{n} x_i(y_i - \beta_0 - \beta_1 x_i) = 0\]

Now substitute \(\beta_0 = \bar{y} - \beta_1 \bar{x}\) from Step 1:

\[\sum_{i=1}^{n} x_i\big(y_i - (\bar{y} - \beta_1 \bar{x}) - \beta_1 x_i\big) = 0\] \[\sum_{i=1}^{n} x_i\big((y_i - \bar{y}) - \beta_1(x_i - \bar{x})\big) = 0\]

Distributing:

\[\sum_{i=1}^{n} x_i(y_i - \bar{y}) - \beta_1 \sum_{i=1}^{n} x_i(x_i - \bar{x}) = 0\]

Now here is a useful algebraic fact: \(\sum x_i(y_i - \bar{y}) = \sum (x_i - \bar{x})(y_i - \bar{y})\), because \(\sum \bar{x}(y_i - \bar{y}) = \bar{x}\sum(y_i - \bar{y}) = \bar{x} \cdot 0 = 0\). Similarly, \(\sum x_i(x_i - \bar{x}) = \sum (x_i - \bar{x})^2\). Applying both:

\[\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y}) - \beta_1 \sum_{i=1}^{n}(x_i - \bar{x})^2 = 0\]

Solving for \(\beta_1\):

\[\boxed{\hat{\beta}_1 = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n}(x_i - \bar{x})^2}}\]

This is the OLS slope estimator. Notice what it says: the slope is the ratio of the sample covariance of \(x\) and \(y\) (the numerator) to the sample variance of \(x\) (the denominator). If \(x\) and \(y\) tend to move together (positive covariance), the slope is positive. If they move in opposite directions, the slope is negative. If \(x\) has no variation at all, the denominator is zero and the slope is undefined — we'll return to this edge case.

Interpreting the slope: the correlation connection

Recall that the sample correlation coefficient is defined as:

\[r = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum(x_i - \bar{x})^2}\sqrt{\sum(y_i - \bar{y})^2}}\]

If we let \(s_x = \sqrt{\frac{1}{n-1}\sum(x_i-\bar{x})^2}\) and \(s_y = \sqrt{\frac{1}{n-1}\sum(y_i-\bar{y})^2}\) be the sample standard deviations, then we can rewrite the slope as:

\[\hat{\beta}_1 = r \cdot \frac{s_y}{s_x}\]

This is a beautiful decomposition: the slope equals the correlation (a unitless number between \(-1\) and \(+1\)) scaled by the ratio of output spread to input spread. If \(x\) and \(y\) are measured in the same units, the slope equals the correlation directly.

Worked example

Fitting a line to five points

Let's compute everything by hand on a tiny dataset. Suppose we have \(n = 5\) observations:

  • \(x\): 1, 2, 3, 4, 5
  • \(y\): 2, 4, 5, 4, 5

Step 1: Compute the means.

\[\bar{x} = \frac{1+2+3+4+5}{5} = \frac{15}{5} = 3\] \[\bar{y} = \frac{2+4+5+4+5}{5} = \frac{20}{5} = 4\]

Step 2: Compute the numerator of \(\hat{\beta}_1\): \(\sum(x_i - \bar{x})(y_i - \bar{y})\).

We compute each term individually:

  • \(i=1\): \((1-3)(2-4) = (-2)(-2) = 4\)
  • \(i=2\): \((2-3)(4-4) = (-1)(0) = 0\)
  • \(i=3\): \((3-3)(5-4) = (0)(1) = 0\)
  • \(i=4\): \((4-3)(4-4) = (1)(0) = 0\)
  • \(i=5\): \((5-3)(5-4) = (2)(1) = 2\)

Sum: \(4 + 0 + 0 + 0 + 2 = 6\).

Step 3: Compute the denominator: \(\sum(x_i - \bar{x})^2\).

  • \(i=1\): \((1-3)^2 = 4\)
  • \(i=2\): \((2-3)^2 = 1\)
  • \(i=3\): \((3-3)^2 = 0\)
  • \(i=4\): \((4-3)^2 = 1\)
  • \(i=5\): \((5-3)^2 = 4\)

Sum: \(4 + 1 + 0 + 1 + 4 = 10\).

Step 4: Compute the slope.

\[\hat{\beta}_1 = \frac{6}{10} = 0.6\]

Step 5: Compute the intercept.

\[\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x} = 4 - (0.6)(3) = 4 - 1.8 = 2.2\]

Step 6: Write the fitted line.

\[\hat{y} = 2.2 + 0.6x\]

Step 7: Compute predictions and residuals.

  • \(x=1\): \(\hat{y} = 2.2 + 0.6(1) = 2.8\), residual \(= 2 - 2.8 = -0.8\)
  • \(x=2\): \(\hat{y} = 2.2 + 0.6(2) = 3.4\), residual \(= 4 - 3.4 = 0.6\)
  • \(x=3\): \(\hat{y} = 2.2 + 0.6(3) = 4.0\), residual \(= 5 - 4.0 = 1.0\)
  • \(x=4\): \(\hat{y} = 2.2 + 0.6(4) = 4.6\), residual \(= 4 - 4.6 = -0.6\)
  • \(x=5\): \(\hat{y} = 2.2 + 0.6(5) = 5.2\), residual \(= 5 - 5.2 = -0.2\)

Step 8: Verify the residuals sum to zero.

\[-0.8 + 0.6 + 1.0 + (-0.6) + (-0.2) = 0\]

This is not a coincidence — it is guaranteed by the first normal equation. The sum of OLS residuals is always exactly zero.

Step 9: Compute RSS.

\[\text{RSS} = (-0.8)^2 + (0.6)^2 + (1.0)^2 + (-0.6)^2 + (-0.2)^2\] \[= 0.64 + 0.36 + 1.00 + 0.36 + 0.04 = 2.40\]

So the fitted line \(\hat{y} = 2.2 + 0.6x\) achieves RSS = 2.40 on this dataset, and no other line can do better under the squared-error criterion.

Measuring fit: \(R^2\)

RSS tells us the absolute error, but it doesn't tell us whether 2.40 is "good" or "bad" without context. A natural question: how much better is our line than just guessing \(\bar{y}\) for every point?

If we had no \(x\) at all, the best constant prediction would be \(\bar{y}\) (this is the same derivation from the worked reference example in the guide — the mean minimizes squared error). The error of that naive baseline is the Total Sum of Squares:

\[\text{TSS} = \sum_{i=1}^{n}(y_i - \bar{y})^2\]

Our regression reduces the error from TSS down to RSS. The fraction of variance explained is:

\[R^2 = 1 - \frac{\text{RSS}}{\text{TSS}}\]

In our example: \(\text{TSS} = (2-4)^2 + (4-4)^2 + (5-4)^2 + (4-4)^2 + (5-4)^2 = 4 + 0 + 1 + 0 + 1 = 6\). So:

\[R^2 = 1 - \frac{2.40}{6} = 1 - 0.4 = 0.6\]

Our line explains 60% of the variance in \(y\). The remaining 40% is unexplained residual variation. \(R^2\) ranges from 0 (the line is no better than guessing the mean) to 1 (the line fits perfectly, all residuals are zero).

Common mistakes

Common mistake: Students often confuse correlation with causation. A high \(\hat{\beta}_1\) tells us that \(x\) and \(y\) move together linearly in the observed data. It does not tell us that changing \(x\) causes \(y\) to change. Ice cream sales and drowning deaths are correlated (both rise in summer), but banning ice cream won't prevent drownings. Regression finds associations; causal claims require experimental design or additional assumptions.

Common mistake: Extrapolation. Our fitted line \(\hat{y} = 2.2 + 0.6x\) was learned from \(x\) values between 1 and 5. If someone asks for a prediction at \(x = 100\), the line will dutifully output \(62.2\), but there is no reason to believe the linear relationship holds that far outside the observed range. Linear regression is a local model — trust it within the range of your data, be deeply skeptical beyond it.

Edge cases

What if all \(x_i\) are the same value? Then \(\sum(x_i - \bar{x})^2 = 0\), and the denominator of \(\hat{\beta}_1\) is zero. The slope is undefined. Geometrically, all data points are stacked vertically — there is no "spread" in \(x\) to determine a tilt. In this degenerate case, the best we can do is predict \(\bar{y}\) for every input, which is equivalent to setting \(\beta_1 = 0\) and \(\beta_0 = \bar{y}\). This is exactly the situation where regression collapses to the constant-mean predictor.

What if the points are perfectly collinear? If every point lies exactly on some line \(y = a + bx\), then RSS = 0 and \(R^2 = 1\). The OLS formulas recover that line exactly. This is the ideal case — real data almost never achieves it, because real data has noise.

What about outliers? Because squared error penalizes large residuals quadratically, a single outlier far from the line can drag the OLS fit dramatically toward it. If you suspect outliers, robust regression methods (using absolute error or Huber loss) are more appropriate. This is a recurring theme: the choice of loss function shapes everything about the resulting model.

Where we go next

We derived everything for a single input \(x\). But real problems have many features — age, blood pressure, cholesterol, all at once. In Chapter 2, we generalize to multiple linear regression, where the same least-squares logic plays out in matrix notation, and the closed-form solution becomes \(\hat{\boldsymbol{\beta}} = (X^\top X)^{-1} X^\top \mathbf{y}\). The geometric intuition — projecting \(\mathbf{y}\) onto the column space of \(X\) — is one of the most important pictures in all of machine learning.
