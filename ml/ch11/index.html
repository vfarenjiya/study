11. Multi-Layer Perceptron & Feed-Forward Neural Networks

Chapter 11 of 14 35 min read

Beyond linear boundaries

Every classifier in Chapters 1–9 produces either a linear decision boundary (logistic regression, LDA, SVM with linear kernel) or a piecewise-constant one (decision trees, kNN). These are powerful but limited: XOR cannot be solved by any single-layer linear model, and many real-world relationships involve interactions that no fixed basis expansion can capture without prior knowledge of the right features.

The question feed-forward neural networks answer is: can we build a model that automatically learns the right nonlinear features from data, composing simple nonlinear transformations into arbitrarily complex functions?

The answer is the multi-layer perceptron (MLP): a stack of affine transformations interleaved with element-wise nonlinearities. Despite its simplicity, the universal approximation theorem guarantees that an MLP with a single hidden layer and sufficient width can approximate any continuous function on a compact domain to arbitrary precision. The challenge is not representational capacity but learning: how do we efficiently compute gradients through a deep composition of nonlinear functions?

The architecture: layers of composed transformations

An MLP with \(L\) layers computes a function \(f(x) = f^{(L)} \circ f^{(L-1)} \circ \cdots \circ f^{(1)}(x)\), where each layer's transformation is:

\[h^{(\ell)} = \sigma\!\left(W^{(\ell)} h^{(\ell-1)} + b^{(\ell)}\right)\]

Here \(h^{(0)} = x \in \mathbb{R}^{d_0}\) is the input, \(W^{(\ell)} \in \mathbb{R}^{d_\ell \times d_{\ell-1}}\) is the weight matrix for layer \(\ell\), \(b^{(\ell)} \in \mathbb{R}^{d_\ell}\) is the bias vector, and \(\sigma\) is a nonlinear activation function applied element-wise. The output \(h^{(L)}\) is the network's prediction.

Without the nonlinearity \(\sigma\), the entire network would collapse to a single affine transformation regardless of depth: the composition of linear maps is linear. The activation function is what gives depth its power.

Choosing activation functions

The choice of \(\sigma\) profoundly affects trainability:

Sigmoid: \(\sigma(z) = \frac{1}{1+e^{-z}}\). Outputs in \((0,1)\). Historically common but suffers from vanishing gradients: \(\sigma'(z) = \sigma(z)(1-\sigma(z)) \leq 0.25\), so gradients shrink exponentially with depth during backpropagation. Rarely used in hidden layers today.

Tanh: \(\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}\). Zero-centered output in \((-1,1)\). Better than sigmoid but still saturates at extremes, causing vanishing gradients.

ReLU: \(\text{ReLU}(z) = \max(0, z)\). Non-saturating for positive inputs (\(\text{ReLU}'(z) = 1\) for \(z > 0\)), enabling gradient flow through deep networks. Computationally cheap. The downside: neurons with \(z < 0\) have zero gradient permanently ("dying ReLU"). Variants like Leaky ReLU (\(\max(\alpha z, z)\) with small \(\alpha > 0\)) mitigate this.

Output layer activations: For regression, use identity (linear). For binary classification, use sigmoid. For multiclass classification, use softmax: \(\text{softmax}(z)_c = \frac{e^{z_c}}{\sum_{c'} e^{z_{c'}}}\).

The loss function

For regression with squared error:

\[\mathcal{L} = \frac{1}{2}\|y - h^{(L)}\|^2\]

For binary classification with cross-entropy (matching logistic regression from Chapter 4):

\[\mathcal{L} = -\big[y \log \hat{y} + (1-y)\log(1-\hat{y})\big]\]

Training means minimizing \(\mathcal{L}\) over all weights and biases \(\{W^{(\ell)}, b^{(\ell)}\}_{\ell=1}^L\) using gradient descent. But computing \(\nabla_{W^{(\ell)}} \mathcal{L}\) requires differentiating through the entire composition — this is where backpropagation enters.

Backpropagation: deriving gradients layer by layer

Backpropagation is simply the chain rule applied systematically to the computational graph of the network. We present the derivation for a general layer \(\ell\), then specialize to a concrete example.

Define the pre-activation at layer \(\ell\):

\[z^{(\ell)} = W^{(\ell)} h^{(\ell-1)} + b^{(\ell)}, \quad h^{(\ell)} = \sigma(z^{(\ell)})\]

Define the error signal (backpropagated gradient) at layer \(\ell\):

\[\delta^{(\ell)} = \nabla_{z^{(\ell)}} \mathcal{L} = \frac{\partial \mathcal{L}}{\partial z^{(\ell)}}\]

Step 1: Output layer error \(\delta^{(L)}\)

At the output layer, \(\delta^{(L)}\) depends on the loss and output activation. For squared error loss with identity output activation:

\[\delta^{(L)} = h^{(L)} - y\]

For cross-entropy loss with sigmoid output (binary classification), a beautiful cancellation occurs:

\[\delta^{(L)} = \hat{y} - y\]

(This is identical to the logistic regression gradient from Chapter 4, confirming consistency.)

Step 2: Backward recursion for hidden layers

For \(\ell = L-1, L-2, \ldots, 1\), apply the chain rule:

\[\delta^{(\ell)} = \left((W^{(\ell+1)})^\top \delta^{(\ell+1)}\right) \odot \sigma'(z^{(\ell)})\]

where \(\odot\) denotes element-wise multiplication. Intuitively: the error signal flows backward through the transpose of the next layer's weights, then gets gated by the local activation derivative. If \(\sigma'\) is near zero (saturated neuron), the gradient is killed — this is the vanishing gradient problem made explicit.

Step 3: Weight and bias gradients

Once all \(\delta^{(\ell)}\) are computed, the parameter gradients follow directly:

\[\boxed{\frac{\partial \mathcal{L}}{\partial W^{(\ell)}} = \delta^{(\ell)} (h^{(\ell-1)})^\top, \quad \frac{\partial \mathcal{L}}{\partial b^{(\ell)}} = \delta^{(\ell)}}\]

These are used in gradient descent updates: \(W^{(\ell)} \leftarrow W^{(\ell)} - \eta \frac{\partial \mathcal{L}}{\partial W^{(\ell)}}\), \(b^{(\ell)} \leftarrow b^{(\ell)} - \eta \frac{\partial \mathcal{L}}{\partial b^{(\ell)}}\), where \(\eta\) is the learning rate.

The key insight: backpropagation computes all gradients in one forward pass (computing all \(z^{(\ell)}, h^{(\ell)}\)) and one backward pass (computing all \(\delta^{(\ell)}\)), making it \(O(\text{network size})\) per sample — no more expensive than evaluating the network itself.

Worked example

One training step on a minimal MLP

Consider a network with 1 input, 2 hidden units (ReLU), and 1 output (identity, squared error loss). Architecture:

\[x \xrightarrow{W^{(1)}, b^{(1)}} z^{(1)} \xrightarrow{\text{ReLU}} h^{(1)} \xrightarrow{W^{(2)}, b^{(2)}} z^{(2)} = \hat{y}\]

Initial parameters:

\[W^{(1)} = \begin{pmatrix} 0.5 \\ -0.5 \end{pmatrix}, \quad b^{(1)} = \begin{pmatrix} 0 \\ 0 \end{pmatrix}, \quad W^{(2)} = \begin{pmatrix} 1 & 1 \end{pmatrix}, \quad b^{(2)} = 0\]

Training sample: \(x = 2\), \(y = 1\). Learning rate \(\eta = 0.1\).

Forward pass:

\[z^{(1)} = W^{(1)} x + b^{(1)} = \begin{pmatrix} 0.5 \cdot 2 \\ -0.5 \cdot 2 \end{pmatrix} + \begin{pmatrix} 0 \\ 0 \end{pmatrix} = \begin{pmatrix} 1 \\ -1 \end{pmatrix}\] \[h^{(1)} = \text{ReLU}(z^{(1)}) = \begin{pmatrix} \max(0, 1) \\ \max(0, -1) \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}\] \[\hat{y} = z^{(2)} = W^{(2)} h^{(1)} + b^{(2)} = \begin{pmatrix} 1 & 1 \end{pmatrix} \begin{pmatrix} 1 \\ 0 \end{pmatrix} + 0 = 1\]

Loss: \(\mathcal{L} = \frac{1}{2}(1 - 1)^2 = 0\). (Coincidentally perfect on this sample — let's change \(y = 0\) to make it interesting.)

Revised target: \(y = 0\). Loss: \(\mathcal{L} = \frac{1}{2}(1 - 0)^2 = 0.5\).

Backward pass:

Output error: \(\delta^{(2)} = \hat{y} - y = 1 - 0 = 1\).

Hidden error: \(\delta^{(1)} = ((W^{(2)})^\top \delta^{(2)}) \odot \text{ReLU}'(z^{(1)})\).

\[(W^{(2)})^\top \delta^{(2)} = \begin{pmatrix} 1 \\ 1 \end{pmatrix} \cdot 1 = \begin{pmatrix} 1 \\ 1 \end{pmatrix}\]

\(\text{ReLU}'(z^{(1)}) = \begin{pmatrix} 1 \\ 0 \end{pmatrix}\) (derivative is 1 where \(z > 0\), 0 otherwise).

\[\delta^{(1)} = \begin{pmatrix} 1 \\ 1 \end{pmatrix} \odot \begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}\]

Note: hidden unit 2 has zero gradient because ReLU killed it (\(z^{(1)}_2 = -1 < 0\)). This is the dying ReLU phenomenon in action.

Parameter gradients:

\[\frac{\partial \mathcal{L}}{\partial W^{(2)}} = \delta^{(2)} (h^{(1)})^\top = 1 \cdot \begin{pmatrix} 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \end{pmatrix}\] \[\frac{\partial \mathcal{L}}{\partial b^{(2)}} = \delta^{(2)} = 1\] \[\frac{\partial \mathcal{L}}{\partial W^{(1)}} = \delta^{(1)} (h^{(0)})^\top = \begin{pmatrix} 1 \\ 0 \end{pmatrix} \cdot 2 = \begin{pmatrix} 2 \\ 0 \end{pmatrix}\] \[\frac{\partial \mathcal{L}}{\partial b^{(1)}} = \delta^{(1)} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}\]

Gradient descent update (\(\eta = 0.1\)):

\[W^{(2)} \leftarrow \begin{pmatrix} 1 & 1 \end{pmatrix} - 0.1 \begin{pmatrix} 1 & 0 \end{pmatrix} = \begin{pmatrix} 0.9 & 1.0 \end{pmatrix}\] \[b^{(2)} \leftarrow 0 - 0.1(1) = -0.1\] \[W^{(1)} \leftarrow \begin{pmatrix} 0.5 \\ -0.5 \end{pmatrix} - 0.1 \begin{pmatrix} 2 \\ 0 \end{pmatrix} = \begin{pmatrix} 0.3 \\ -0.5 \end{pmatrix}\] \[b^{(1)} \leftarrow \begin{pmatrix} 0 \\ 0 \end{pmatrix} - 0.1 \begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} -0.1 \\ 0 \end{pmatrix}\]

Notice that \(W^{(1)}_{2,:}\) and \(b^{(1)}_2\) did not change at all — hidden unit 2 received zero gradient and is effectively dead for this input. Over many training samples, if unit 2 never activates, it remains permanently useless. This motivates careful initialization and leaky ReLU variants.

Initialization matters

Initializing all weights to zero makes every hidden unit compute the same function — symmetry is never broken, and the network behaves as if it has one hidden unit. Weights must be initialized randomly.

But random scale matters enormously. Too large: activations saturate, gradients vanish. Too small: signals shrink exponentially with depth, gradients vanish. Xavier/Glorot initialization sets \(W^{(\ell)}_{ij} \sim \mathcal{N}(0, 2/(d_{\ell-1} + d_\ell))\), maintaining unit variance of activations across layers for tanh/sigmoid. He initialization uses \(\mathcal{N}(0, 2/d_{\ell-1})\) for ReLU networks, accounting for the fact that ReLU halves the variance (half the inputs are zeroed).

Regularization in neural networks

Neural networks have enormous capacity and easily overfit. Regularization strategies include:

  • Weight decay (\(\ell_2\) penalty): Adds \(\frac{\lambda}{2}\sum_\ell \|W^{(\ell)}\|_F^2\) to the loss. Exactly analogous to ridge regression (Chapter 3). Prevents weights from growing too large.
  • Dropout: During training, randomly zero out hidden units with probability \(p\). Forces redundant representations and acts as implicit ensemble averaging. At test time, scale activations by \(1-p\) (or use inverted dropout during training).
  • Early stopping: Monitor validation loss during training; stop when it begins to increase. Effectively limits the number of gradient steps, constraining model complexity. Connects directly to the bias-variance framework of Chapter 10.

Common mistake

Common mistake: Students often confuse the dimensions of weight matrices and error signals during backpropagation. The weight matrix \(W^{(\ell)} \in \mathbb{R}^{d_\ell \times d_{\ell-1}}\) maps from layer \(\ell-1\) (dimension \(d_{\ell-1}\)) to layer \(\ell\) (dimension \(d_\ell\)). The backward pass uses \((W^{(\ell+1)})^\top \in \mathbb{R}^{d_\ell \times d_{\ell+1}}\) to map error signals from layer \(\ell+1\) back to layer \(\ell\). Getting these transposes wrong produces dimension mismatches or silently incorrect gradients. Always verify dimensions: \(\delta^{(\ell)} \in \mathbb{R}^{d_\ell}\), \(\frac{\partial \mathcal{L}}{\partial W^{(\ell)}} \in \mathbb{R}^{d_\ell \times d_{\ell-1}}\). Dimensional analysis catches most backpropagation implementation errors before they produce subtle numerical bugs.

Edge case

What happens with a single hidden layer and linear activation everywhere? The network computes \(W^{(2)} \sigma(W^{(1)} x + b^{(1)}) + b^{(2)}\) with \(\sigma(z) = z\), which simplifies to \((W^{(2)} W^{(1)}) x + (W^{(2)} b^{(1)} + b^{(2)})\) — a single affine transformation. Depth adds nothing without nonlinearity. This is why activation functions are non-negotiable.

What about the universal approximation theorem? It guarantees existence of weights achieving arbitrary accuracy but says nothing about whether gradient descent can find them, how many hidden units are needed, or how sample complexity scales. In practice, deeper networks with fewer total parameters often generalize better than shallow wide ones, suggesting that depth provides an inductive bias toward compositional functions that matches the structure of real-world data. This remains an active area of theoretical research.
