14. Feed-Forward Neural Network

Chapter 14 of 17 27 min read

Training as optimization: from architecture to learning

Chapter 13 defined the feed-forward neural network as a compositional function \(\hat y = f(\mathbf{x}; \boldsymbol\theta)\) parameterized by weights and biases \(\boldsymbol\theta = \{W^{(\ell)}, \mathbf{b}^{(\ell)}\}_{\ell=1}^L\). This chapter addresses the complementary question: how do we find good parameters? Training a neural network is an instance of empirical risk minimization (Chapter 1): minimize the average loss over training data,

\[ \min_{\boldsymbol\theta} \hat R(\boldsymbol\theta) = \frac{1}{n} \sum_{i=1}^{n} L\big(f(\mathbf{x}_i; \boldsymbol\theta), y_i\big) \]

Unlike linear models (Chapters 2–5), this objective is non-convex in \(\boldsymbol\theta\) due to nonlinear activations. Global optimization is NP-hard in general; practical training relies on gradient-based local optimization. The key enabler is backpropagation, an efficient algorithm for computing gradients \(\nabla_{\boldsymbol\theta} \hat R\) via the chain rule. Once gradients are available, iterative update rules (SGD, momentum, Adam) navigate the loss landscape toward locally optimal parameters.

This chapter derives backpropagation from first principles, presents the major optimization algorithms with their trade-offs, covers regularization techniques specific to neural networks (dropout, batch normalization, weight decay), and completes the hand-computed example from Chapter 13 with a full backward pass. Together, these two chapters provide the complete foundation for understanding modern deep learning.

Common mistake: treating backpropagation as a learning algorithm rather than a gradient computation algorithm. Backpropagation computes \(\nabla_{\boldsymbol\theta} L\); it does not update parameters. The learning algorithm is the optimizer (SGD, Adam, etc.) that uses those gradients. Confusing the two leads to misunderstandings about what can be modified independently: you can change optimizers without changing backpropagation, and vice versa (e.g., for custom gradient estimators).

Backpropagation: deriving gradients via the chain rule

Consider a single training example \((\mathbf{x}, y)\) and loss \(L(\hat y, y)\). The forward pass computes intermediate activations layer by layer:

\[ \mathbf{z}^{(\ell)} = W^{(\ell)} \mathbf{h}^{(\ell-1)} + \mathbf{b}^{(\ell)}, \quad \mathbf{h}^{(\ell)} = \sigma(\mathbf{z}^{(\ell)}), \quad \ell = 1, \dots, L \]

with \(\mathbf{h}^{(0)} = \mathbf{x}\) and \(\hat y = g(\mathbf{z}^{(L)})\). Backpropagation computes \(\partial L / \partial W^{(\ell)}\) and \(\partial L / \partial \mathbf{b}^{(\ell)}\) for all layers by applying the chain rule backwards from output to input. Define the error signal at layer \(\ell\) as:

\[ \boldsymbol\delta^{(\ell)} = \frac{\partial L}{\partial \mathbf{z}^{(\ell)}} \]

Output layer: By the chain rule through the output activation \(g\):

\[ \boldsymbol\delta^{(L)} = \frac{\partial L}{\partial \hat y} \cdot \frac{\partial \hat y}{\partial \mathbf{z}^{(L)}} = \nabla_{\hat y} L \odot g'(\mathbf{z}^{(L)}) \]

where \(\odot\) denotes element-wise multiplication. For cross-entropy loss with softmax output, this simplifies beautifully to \(\boldsymbol\delta^{(L)} = \hat{\mathbf{y}} - \mathbf{y}\) (one-hot encoded), eliminating the explicit derivative term entirely — a key reason this pairing is standard for classification.

Hidden layers: Propagating backwards through layer \(\ell\):

\[ \boldsymbol\delta^{(\ell)} = \left( (W^{(\ell+1)})^\top \boldsymbol\delta^{(\ell+1)} \right) \odot \sigma'(\mathbf{z}^{(\ell)}) \]

This is the core recurrence: the error signal at layer \(\ell\) equals the transposed weight matrix times the next layer's error, modulated by the local activation derivative. The transpose arises because gradients flow "backwards" through the same linear transformation that propagated activations forward.

Parameter gradients: Once \(\boldsymbol\delta^{(\ell)}\) is computed, parameter gradients follow directly:

\[ \frac{\partial L}{\partial W^{(\ell)}} = \boldsymbol\delta^{(\ell)} (\mathbf{h}^{(\ell-1)})^\top, \qquad \frac{\partial L}{\partial \mathbf{b}^{(\ell)}} = \boldsymbol\delta^{(\ell)} \]

The entire backward pass requires one pass through the network (same cost as forward pass), yielding all parameter gradients simultaneously. This efficiency — \(O(\text{forward cost})\) rather than \(O(p \times \text{forward cost})\) for finite differences — is what makes training deep networks feasible.

Edge case: when \(\sigma'(z) = 0\) (saturated sigmoid/tanh or dead ReLU), \(\boldsymbol\delta^{(\ell)} = \mathbf{0}\) and all upstream gradients vanish. This is the vanishing gradient problem that motivated ReLU activations (Chapter 13) and residual connections. Conversely, if \(\|W^{(\ell+1)}\|\) is large and \(\sigma'\) doesn't sufficiently dampen, gradients can explode exponentially through layers. Gradient clipping (capping \(\|\nabla L\|\) at a threshold) prevents numerical overflow but doesn't solve the underlying instability. Proper initialization (He/Xavier) and batch normalization mitigate both pathologies.

Worked example: complete backward pass

We continue the exact network from Chapter 13's forward pass example. Recall: input \(\mathbf{x} = (1, 2)^\top\), true label \(y = 1\) (binary classification), hidden ReLU, sigmoid output. Forward pass yielded \(\mathbf{z}^{(1)} = (-1, 2)^\top\), \(\mathbf{h}^{(1)} = (0, 2)^\top\), \(z^{(2)} = -3.5\), \(\hat y = 0.0293\).

Loss: Binary cross-entropy \(L = -[y \log \hat y + (1-y)\log(1-\hat y)] = -\log(0.0293) = 3.530\).

Output layer gradient: For BCE + sigmoid, \(\delta^{(2)} = \hat y - y = 0.0293 - 1 = -0.9707\).

Gradients for \(W^{(2)}, b^{(2)}\):

\[ \frac{\partial L}{\partial W^{(2)}} = \delta^{(2)} (\mathbf{h}^{(1)})^\top = -0.9707 \begin{pmatrix} 0 & 2 \end{pmatrix} = \begin{pmatrix} 0 & -1.9414 \end{pmatrix} \] \[ \frac{\partial L}{\partial b^{(2)}} = \delta^{(2)} = -0.9707 \]

Note \(\partial L / \partial W_{11}^{(2)} = 0\) because \(h_1^{(1)} = 0\) (dead ReLU) — consistent with forward pass observation.

Backpropagate to hidden layer: ReLU derivative: \(\sigma'(z) = \mathbb{1}[z > 0]\). So \(\sigma'(\mathbf{z}^{(1)}) = (0, 1)^\top\) (first unit dead, second active).

\[ \boldsymbol\delta^{(1)} = \left( (W^{(2)})^\top \delta^{(2)} \right) \odot \sigma'(\mathbf{z}^{(1)}) = \left[ \begin{pmatrix} 1 \\ -2 \end{pmatrix} (-0.9707) \right] \odot \begin{pmatrix} 0 \\ 1 \end{pmatrix} = \begin{pmatrix} -0.9707 \\ 1.9414 \end{pmatrix} \odot \begin{pmatrix} 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 1.9414 \end{pmatrix} \]

First component is zeroed by dead ReLU — no gradient flows to first hidden unit's incoming weights.

Gradients for \(W^{(1)}, \mathbf{b}^{(1)}\):

\[ \frac{\partial L}{\partial W^{(1)}} = \boldsymbol\delta^{(1)} \mathbf{x}^\top = \begin{pmatrix} 0 \\ 1.9414 \end{pmatrix} \begin{pmatrix} 1 & 2 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 1.9414 & 3.8828 \end{pmatrix} \] \[ \frac{\partial L}{\partial \mathbf{b}^{(1)}} = \boldsymbol\delta^{(1)} = \begin{pmatrix} 0 \\ 1.9414 \end{pmatrix} \]

Interpretation: The gradient pushes \(W_{21}^{(1)}\) and \(W_{22}^{(1)}\) upward (positive gradient → decrease loss by decreasing weights? Wait: gradient descent updates \(W \leftarrow W - \eta \nabla_W L\). Positive gradient means weight decreases. Here \(\partial L/\partial W_{21}^{(1)} = 1.94 > 0\), so \(W_{21}^{(1)}\) decreases. Since \(W_{21}^{(1)} = 1\) currently contributed positively to \(z_2^{(1)} = 2\), reducing it would reduce \(h_2^{(1)}\), which currently feeds negatively into \(z^{(2)}\) via \(W_{12}^{(2)} = -2\). Reducing \(h_2^{(1)}\) increases \(z^{(2)}\) (less negative), increasing \(\hat y\) toward the true label 1. ✓ Gradient direction is correct. Sensitivity check: if the first hidden unit were alive (\(z_1^{(1)} > 0\)), \(\delta_1^{(1)}\) would be nonzero and \(W_{11}^{(1)}, W_{12}^{(1)}\) would receive gradients. Dead units create permanent blind spots unless reactivated by noise, different data, or Leaky ReLU — illustrating why initialization and activation choice matter critically for trainability.

Optimization algorithms: SGD, momentum, and Adam

With gradients computed, parameters are updated iteratively. Three algorithms dominate practice:

Stochastic Gradient Descent (SGD)

\[ \boldsymbol\theta_{t+1} = \boldsymbol\theta_t - \eta \nabla_{\boldsymbol\theta} \hat R_B(\boldsymbol\theta_t) \]

where \(\hat R_B\) is the loss on a mini-batch \(B\) of size \(m \ll n\), and \(\eta\) is the learning rate. Mini-batching provides noisy but cheap gradient estimates, enabling progress before full-data passes complete. Learning rate selection is critical: too large diverges; too small stagnates. Schedules (step decay, cosine annealing, warmup) adapt \(\eta\) during training.

Momentum

\[ \mathbf{v}_{t+1} = \mu \mathbf{v}_t + \nabla_{\boldsymbol\theta} \hat R_B(\boldsymbol\theta_t), \quad \boldsymbol\theta_{t+1} = \boldsymbol\theta_t - \eta \mathbf{v}_{t+1} \]

Momentum accumulates past gradients with exponential decay \(\mu \in [0, 1)\) (typically 0.9). Benefits: accelerates convergence along consistent gradient directions, dampens oscillations in ravine-shaped loss landscapes, and helps escape shallow local minima. Nesterov accelerated gradient evaluates the gradient at the lookahead position \(\boldsymbol\theta_t - \mu \mathbf{v}_t\), providing better theoretical convergence rates.

Adam (Adaptive Moment Estimation)

\[ \mathbf{m}_t = \beta_1 \mathbf{m}_{t-1} + (1-\beta_1) \mathbf{g}_t, \quad \mathbf{v}_t = \beta_2 \mathbf{v}_{t-1} + (1-\beta_2) \mathbf{g}_t^2 \] \[ \hat{\mathbf{m}}_t = \mathbf{m}_t / (1-\beta_1^t), \quad \hat{\mathbf{v}}_t = \mathbf{v}_t / (1-\beta_2^t), \quad \boldsymbol\theta_{t+1} = \boldsymbol\theta_t - \frac{\eta}{\sqrt{\hat{\mathbf{v}}_t} + \epsilon} \hat{\mathbf{m}}_t \]

Adam maintains per-parameter adaptive learning rates via running averages of first moment (mean) and second moment (variance) of gradients. Bias correction compensates for initialization at zero. Default hyperparameters \(\beta_1 = 0.9, \beta_2 = 0.999, \epsilon = 10^{-8}\) work well across diverse tasks. Adam converges faster than SGD initially but may generalize slightly worse; SGD with momentum often achieves better final test accuracy with careful tuning.

Common mistake: using Adam's default learning rate \(\eta = 0.001\) universally. While reasonable as a starting point, optimal \(\eta\) varies by orders of magnitude across architectures and datasets. Always perform learning rate sweeps or use LR finders. Also beware that Adam's adaptivity can mask poor conditioning; if Adam trains but SGD fails, the loss landscape may be ill-conditioned and worth diagnosing rather than papering over.

Regularization for neural networks

Neural networks have enormous capacity and overfit readily. Beyond classical regularization (weight decay = \(\ell_2\) penalty, Chapter 4), three techniques are specific to deep learning:

Dropout

During training, randomly zero each hidden unit's activation with probability \(p\) (typically 0.2–0.5), scaling surviving activations by \(1/(1-p)\) to preserve expected values. At test time, use full network without dropout. Dropout prevents co-adaptation of features (units cannot rely on specific partners being present), effectively training an ensemble of \(2^m\) subnetworks. Mathematically equivalent to adding multiplicative noise to hidden representations.

Batch Normalization

Normalize each mini-batch's layer inputs to zero mean and unit variance, then apply learnable scale \(\gamma\) and shift \(\beta\): \(\hat{\mathbf{z}} = \gamma \odot \frac{\mathbf{z} - \hat{\boldsymbol\mu}_B}{\sqrt{\hat{\boldsymbol\sigma}_B^2 + \epsilon}} + \boldsymbol\beta\). Stabilizes training by reducing internal covariate shift, allows higher learning rates, and acts as mild regularizer due to mini-batch noise. At test time, use running population statistics instead of batch statistics.

Weight Decay vs. \(\ell_2\) Regularization

In SGD, weight decay (\(\boldsymbol\theta \leftarrow (1-\lambda)\boldsymbol\theta - \eta \nabla L\)) and \(\ell_2\) regularization (\(\nabla(L + \frac{\lambda}{2}\|\boldsymbol\theta\|^2)\)) are equivalent. In adaptive optimizers (Adam), they differ: decoupled weight decay applies decay directly to parameters independent of gradient history, while \(\ell_2\) modifies the gradient before adaptation. Decoupled weight decay (AdamW) generally outperforms \(\ell_2\) regularization with Adam and is now the recommended default.

Edge case: dropout applied to recurrent connections or attention mechanisms requires specialized variants (variational dropout, DropConnect) to maintain temporal consistency. Batch normalization interacts poorly with very small batch sizes (< 8); Layer Normalization or Group Normalization are preferred alternatives. Weight decay should typically NOT be applied to bias terms or batch norm parameters, as these don't contribute to overfitting in the same way.

Worked example: comparing optimizer trajectories

Minimize \(f(w_1, w_2) = 0.1 w_1^2 + 10 w_2^2\) (elongated valley, condition number 100). Start at \((5, 5)\), \(\eta = 0.01\).

SGD: \(\nabla f = (w_1, 20w_2)\). Step 1: \((5, 5) - 0.01(1, 100) = (4.99, 4.0)\). Step 2: \((4.99, 4.0) - 0.01(0.998, 80) = (4.98, 3.2)\). Oscillates heavily in \(w_2\) direction while barely moving in \(w_1\). After 100 steps: approximately \((4.0, 0.07)\) — still far from optimum in \(w_1\).

Momentum (\(\mu=0.9\)): Accumulates velocity in consistent \(w_2\) direction, damping oscillations. After 100 steps: approximately \((2.5, 0.001)\) — much further along \(w_1\) due to accumulated momentum carrying through the valley.

Adam: Adapts per-parameter LR: \(w_2\) gets smaller effective LR (large gradient variance), \(w_1\) gets larger effective LR (small gradient). After 100 steps: approximately \((0.3, 0.0001)\) — near optimum in both dimensions. Sensitivity check: with \(\eta = 0.1\), SGD diverges immediately (overshoots in \(w_2\)); momentum overshoots then recovers; Adam remains stable due to adaptivity. With \(\eta = 0.001\), all converge but SGD takes ~10× longer. This illustrates why adaptive methods dominate early-stage prototyping while tuned SGD+momentum wins final performance in competitive settings.

Vanishing and exploding gradients: diagnosis and remedies

Gradient flow through deep networks is governed by products of Jacobians. For a network with \(L\) layers, the gradient w.r.t. early-layer parameters involves:

\[ \frac{\partial L}{\partial \mathbf{z}^{(1)}} = \prod_{\ell=1}^{L-1} \operatorname{diag}(\sigma'(\mathbf{z}^{(\ell)})) \, (W^{(\ell+1)})^\top \cdot \boldsymbol\delta^{(L)} \]

If \(\|\operatorname{diag}(\sigma') (W^{(\ell+1)})^\top\| < 1\) consistently, gradients decay exponentially (vanishing); if \(> 1\), they grow exponentially (exploding). Sigmoid/tanh saturate (\(\sigma' \leq 0.25\)), causing vanishing. Large weight norms cause exploding. Both prevent learning in deep networks.

Remedies:

  • ReLU activations: \(\sigma' = 1\) for active units, avoiding systematic attenuation.
  • Careful initialization: He initialization (\(W \sim \mathcal{N}(0, 2/n_{\text{in}})\)) for ReLU; Xavier (\(W \sim \mathcal{N}(0, 1/n_{\text{in}})\)) for sigmoid/tanh. Maintains unit variance through layers.
  • Residual connections: \(\mathbf{h}^{(\ell+1)} = F(\mathbf{h}^{(\ell)}) + \mathbf{h}^{(\ell)}\) provides identity shortcut for gradient flow even when \(F\) has small derivatives.
  • Batch/Layer Normalization: Keeps activations in non-saturating regime.
  • Gradient clipping: Caps global norm \(\|\nabla L\| \leq c\) to prevent explosion (essential for RNNs).

Edge case: even with ReLU, deep networks can suffer from "dying ReLU" where units permanently deactivate, creating zero-gradient pathways. Leaky ReLU, ELU, or GELU maintain nonzero gradients for negative inputs. Also note that vanishing gradients affect training, not inference; a trained network with small gradients can still compute correct outputs. The problem is learnability, not expressivity.

Connection to the broader framework

Feed-forward network training unifies nearly every concept in this book. Chapter 1's ERM is the objective; backpropagation enables its optimization. Chapter 4's ridge regularization reappears as weight decay. Chapter 5's logistic regression is the single-layer special case with BCE loss. Chapter 11's bias-variance trade-off governs architecture and regularization choices. Chapter 12's cross-validation selects hyperparameters (learning rate, dropout rate, batch norm). And Chapter 13's architecture defines the function class whose parameters this chapter learns.

Master feed-forward training not as a collection of tricks but as the systematic application of calculus, optimization, and statistical principles to compositional functions. If you can derive backpropagation from the chain rule, implement a backward pass by hand, explain why Adam adapts per-parameter learning rates, diagnose vanishing gradients from activation statistics, and articulate when SGD beats Adam (and vice versa), you have internalized the machinery that powers modern AI. Everything beyond this — CNNs, transformers, diffusion models — builds on these foundations.
