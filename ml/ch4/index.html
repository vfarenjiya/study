4. Logistic Regression

Chapter 4 of 14 30 min read

From continuous targets to discrete labels

In Chapters 1–3, our target \(y\) was a continuous number, and we predicted it with a linear function (possibly regularized). But many of the most important prediction problems have categorical targets: will this email be spam or not? Does this tumor look malignant or benign? Will this customer churn or stay?

The fundamental question logistic regression answers is: how do we adapt the linear modeling framework to predict probabilities over discrete categories instead of continuous numbers?

We focus on binary classification, where \(y \in \{0, 1\}\). The extension to multiple classes (multinomial logistic regression) follows similar principles but adds complexity that is beyond the immediate scope. Binary classification already contains every essential idea.

Why not just use linear regression on binary targets?

A naive first attempt: treat \(y \in \{0, 1\}\) as a number and fit OLS. Predict \(\hat{y} = \beta_0 + \beta_1 x\), and classify as 1 if \(\hat{y} > 0.5\), else 0. What goes wrong?

Three things. First, the predictions are unbounded: \(\hat{y}\) can be negative or greater than 1, which makes no sense as a probability. Second, the relationship between features and a binary outcome is inherently nonlinear — the probability should saturate near 0 and 1, not grow linearly forever. Third, the homoscedasticity assumption of OLS (constant variance of errors) is violated: for binary data, \(\text{Var}(y|x) = p(x)(1 - p(x))\), which depends on \(x\) itself.

We need a model that maps a linear combination of features to a value strictly between 0 and 1, interpreted as \(P(y = 1 | x)\). This requires a link function.

The sigmoid function: squashing to [0, 1]

We want a function \(\sigma : \mathbb{R} \to (0, 1)\) that is smooth, monotone increasing, and satisfies \(\lim_{z \to -\infty} \sigma(z) = 0\) and \(\lim_{z \to +\infty} \sigma(z) = 1\). The canonical choice is the logistic sigmoid:

\[\sigma(z) = \frac{1}{1 + e^{-z}}\]

Let's verify the boundary behavior. As \(z \to +\infty\), \(e^{-z} \to 0\), so \(\sigma(z) \to \frac{1}{1+0} = 1\). As \(z \to -\infty\), \(e^{-z} \to \infty\), so \(\sigma(z) \to \frac{1}{\infty} = 0\). At \(z = 0\), \(\sigma(0) = \frac{1}{2}\). The function is S-shaped, smoothly transitioning from near-zero to near-one.

There is an extremely useful algebraic identity for the sigmoid that we will need repeatedly:

\[1 - \sigma(z) = 1 - \frac{1}{1 + e^{-z}} = \frac{e^{-z}}{1 + e^{-z}} = \frac{1}{e^z + 1} = \sigma(-z)\]

So the complement of the sigmoid is just the sigmoid evaluated at the negated input. This symmetry simplifies many derivations below.

Another critical property: the derivative of the sigmoid has a clean closed form. Differentiating using the chain rule:

\[\sigma'(z) = \frac{d}{dz}\left(\frac{1}{1 + e^{-z}}\right) = \frac{e^{-z}}{(1 + e^{-z})^2} = \frac{1}{1 + e^{-z}} \cdot \frac{e^{-z}}{1 + e^{-z}} = \sigma(z)(1 - \sigma(z))\]

The derivative equals the function times its own complement. This elegant self-referential property is what makes logistic regression tractable.

The logistic regression model

We now define the model. Given features \(x \in \mathbb{R}^p\) and parameters \(\boldsymbol{\beta} \in \mathbb{R}^{p+1}\) (including intercept), the predicted probability is:

\[P(y = 1 | x) = \sigma(\boldsymbol{\beta}^\top x) = \frac{1}{1 + e^{-\boldsymbol{\beta}^\top x}}\]

where we adopt the convention that \(x\) includes a leading 1 for the intercept (as in Chapter 2). The quantity \(z = \boldsymbol{\beta}^\top x\) is called the linear predictor or logit score. The sigmoid squashes it into a valid probability.

For classification, we threshold at 0.5: predict class 1 if \(\sigma(\boldsymbol{\beta}^\top x) > 0.5\), which is equivalent to \(\boldsymbol{\beta}^\top x > 0\) (since \(\sigma(z) > 0.5 \iff z > 0\)). The decision boundary is therefore the hyperplane \(\boldsymbol{\beta}^\top x = 0\) — a linear boundary in feature space, despite the nonlinear probability mapping.

Maximum likelihood estimation

Unlike OLS, logistic regression has no closed-form solution. We estimate \(\boldsymbol{\beta}\) by maximum likelihood. Given independent observations \(\{(x_i, y_i)\}_{i=1}^n\), the likelihood of the data under the model is:

\[L(\boldsymbol{\beta}) = \prod_{i=1}^{n} P(y_i | x_i) = \prod_{i=1}^{n} \sigma(\boldsymbol{\beta}^\top x_i)^{y_i} \big(1 - \sigma(\boldsymbol{\beta}^\top x_i)\big)^{1 - y_i}\]

This compact expression works because when \(y_i = 1\), only the first factor survives (\(\sigma^1 \cdot (1-\sigma)^0 = \sigma\)), and when \(y_i = 0\), only the second factor survives (\(\sigma^0 \cdot (1-\sigma)^1 = 1-\sigma\)).

Maximizing the product directly is numerically unstable (many small numbers multiplied together underflow). We maximize the log-likelihood instead, which converts products to sums and preserves the location of the maximum (since log is monotone):

\[\ell(\boldsymbol{\beta}) = \sum_{i=1}^{n} \Big[ y_i \log \sigma(\boldsymbol{\beta}^\top x_i) + (1 - y_i) \log\big(1 - \sigma(\boldsymbol{\beta}^\top x_i)\big) \Big]\]

Deriving the gradient

To maximize \(\ell(\boldsymbol{\beta})\), we compute its gradient with respect to \(\boldsymbol{\beta}\). Let \(z_i = \boldsymbol{\beta}^\top x_i\) and \(p_i = \sigma(z_i)\). Using the chain rule and the sigmoid derivative \(\sigma'(z) = \sigma(z)(1 - \sigma(z))\):

\[\frac{\partial \ell}{\partial \boldsymbol{\beta}} = \sum_{i=1}^{n} \left[ y_i \frac{\sigma'(z_i)}{\sigma(z_i)} x_i + (1 - y_i) \frac{-\sigma'(z_i)}{1 - \sigma(z_i)} x_i \right]\]

Substituting \(\sigma'(z_i) = p_i(1 - p_i)\):

\[\frac{\partial \ell}{\partial \boldsymbol{\beta}} = \sum_{i=1}^{n} \left[ y_i \frac{p_i(1-p_i)}{p_i} x_i - (1-y_i) \frac{p_i(1-p_i)}{1-p_i} x_i \right]\] \[= \sum_{i=1}^{n} \big[ y_i(1 - p_i) - (1 - y_i)p_i \big] x_i\] \[= \sum_{i=1}^{n} (y_i - p_i) x_i\]

In matrix notation, letting \(\mathbf{p} = \sigma(X\boldsymbol{\beta})\) denote the vector of predicted probabilities:

\[\boxed{\nabla_{\boldsymbol{\beta}} \ell(\boldsymbol{\beta}) = X^\top (\mathbf{y} - \mathbf{p})}This gradient has a beautiful interpretation: it is the same form as the OLS gradient \(X^\top(\mathbf{y} - X\boldsymbol{\beta})\), but with the linear prediction \(X\boldsymbol{\beta}\) replaced by the nonlinear probability prediction \(\mathbf{p}\). Setting the gradient to zero gives the score equations:

\[X^\top (\mathbf{y} - \mathbf{p}) = \mathbf{0}\]

Unlike the OLS normal equations, these are nonlinear in \(\boldsymbol{\beta}\) (because \(\mathbf{p} = \sigma(X\boldsymbol{\beta})\) is nonlinear). There is no closed-form solution. We must solve them iteratively using numerical optimization — typically Newton-Raphson (also called Iteratively Reweighted Least Squares, IRLS) or gradient ascent.

Worked example

One step of gradient ascent on three points

Let's perform one iteration of gradient ascent manually on a tiny dataset with \(p = 1\) feature (plus intercept). Data:

  • \(x_1 = 0, y_1 = 0\)
  • \(x_2 = 1, y_2 = 1\)
  • \(x_3 = 2, y_3 = 1\)

Design matrix (with intercept column):

\[X = \begin{pmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2 \end{pmatrix}, \quad \mathbf{y} = \begin{pmatrix} 0 \\ 1 \\ 1 \end{pmatrix}\]

Step 1: Initialize parameters. Start at \(\boldsymbol{\beta}^{(0)} = (0, 0)^\top\).

Step 2: Compute linear predictors and probabilities.

\[z = X\boldsymbol{\beta}^{(0)} = \begin{pmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2 \end{pmatrix} \begin{pmatrix} 0 \\ 0 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}\] \[\mathbf{p} = \sigma(\mathbf{z}) = \begin{pmatrix} 0.5 \\ 0.5 \\ 0.5 \end{pmatrix}\]

(Since \(\sigma(0) = 0.5\).)

Step 3: Compute the gradient.

\[\mathbf{y} - \mathbf{p} = \begin{pmatrix} 0 - 0.5 \\ 1 - 0.5 \\ 1 - 0.5 \end{pmatrix} = \begin{pmatrix} -0.5 \\ 0.5 \\ 0.5 \end{pmatrix}\] \[\nabla \ell = X^\top (\mathbf{y} - \mathbf{p}) = \begin{pmatrix} 1 & 1 & 1 \\ 0 & 1 & 2 \end{pmatrix} \begin{pmatrix} -0.5 \\ 0.5 \\ 0.5 \end{pmatrix} = \begin{pmatrix} -0.5 + 0.5 + 0.5 \\ 0 + 0.5 + 1.0 \end{pmatrix} = \begin{pmatrix} 0.5 \\ 1.5 \end{pmatrix}\]

Step 4: Take a gradient ascent step. With learning rate \(\eta = 0.5\):

\[\boldsymbol{\beta}^{(1)} = \boldsymbol{\beta}^{(0)} + \eta \nabla \ell = \begin{pmatrix} 0 \\ 0 \end{pmatrix} + 0.5 \begin{pmatrix} 0.5 \\ 1.5 \end{pmatrix} = \begin{pmatrix} 0.25 \\ 0.75 \end{pmatrix}\]

Step 5: Verify improvement. Compute the log-likelihood before and after.

At \(\boldsymbol{\beta}^{(0)} = (0,0)\): all \(p_i = 0.5\), so

\[\ell^{(0)} = 0 \cdot \log(0.5) + 1 \cdot \log(0.5) + 1 \cdot \log(0.5) + (1-0)\log(0.5) + (1-1)\log(0.5) + (1-1)\log(0.5)\]

Simplifying (only terms where the exponent is nonzero contribute):

\[\ell^{(0)} = \log(0.5) + \log(0.5) + \log(0.5) = 3\log(0.5) \approx -2.079\]

At \(\boldsymbol{\beta}^{(1)} = (0.25, 0.75)\):

  • \(z_1 = 0.25 + 0.75(0) = 0.25\), \(p_1 = \sigma(0.25) \approx 0.562\)
  • \(z_2 = 0.25 + 0.75(1) = 1.00\), \(p_2 = \sigma(1.00) \approx 0.731\)
  • \(z_3 = 0.25 + 0.75(2) = 1.75\), \(p_3 = \sigma(1.75) \approx 0.852\)
\[\ell^{(1)} = (1-0)\log(1-0.562) + 1 \cdot \log(0.731) + 1 \cdot \log(0.852)\] \[= \log(0.438) + \log(0.731) + \log(0.852) \approx -0.826 + (-0.313) + (-0.160) = -1.299\]

The log-likelihood improved from \(-2.079\) to \(-1.299\), confirming that the gradient step moved us toward the maximum. Repeating this process converges to the MLE \(\hat{\boldsymbol{\beta}}\).

Interpreting coefficients: odds and log-odds

The sigmoid model implies:

\[\log \frac{P(y=1|x)}{P(y=0|x)} = \log \frac{\sigma(\boldsymbol{\beta}^\top x)}{1 - \sigma(\boldsymbol{\beta}^\top x)} = \boldsymbol{\beta}^\top x\]

The left side is the log-odds (or logit) of the positive class. So logistic regression is literally a linear model for the log-odds. A unit increase in feature \(x_j\) increases the log-odds by \(\beta_j\), or equivalently multiplies the odds by \(e^{\beta_j}\). This multiplicative interpretation on the odds scale is often more meaningful than the additive interpretation on the log-odds scale.

Common mistake

Common mistake: Students often interpret \(\hat{\beta}_j\) as "the change in probability per unit change in \(x_j\)." This is incorrect. Because of the sigmoid nonlinearity, the marginal effect \(\frac{\partial P(y=1|x)}{\partial x_j} = \beta_j \sigma(\boldsymbol{\beta}^\top x)(1 - \sigma(\boldsymbol{\beta}^\top x))\) depends on the current value of \(x\). The effect is largest when \(\boldsymbol{\beta}^\top x \approx 0\) (probability near 0.5) and vanishes as the probability approaches 0 or 1. Always report marginal effects at specific values of \(x\) (e.g., at the mean), not as universal constants.

Edge case

Perfect separation: If there exists a hyperplane that perfectly separates the two classes, the likelihood can be driven arbitrarily close to 1 by sending \(\|\boldsymbol{\beta}\| \to \infty\) along the separating direction. The MLE does not exist as a finite vector — the optimization diverges. In practice, software may return extremely large coefficients with huge standard errors. Regularization (adding an \(\ell_2\) penalty to the log-likelihood, analogous to ridge regression from Chapter 3) prevents this divergence and always yields a finite solution. This is another instance where the bias-variance tradeoff (Chapter 10) manifests concretely.

Where we go next

Logistic regression assumes a parametric form for \(P(y|x)\): specifically, that the log-odds are linear in \(x\). But what if we make no parametric assumptions at all and instead classify based on local similarity to training examples? Chapter 5 introduces k-nearest neighbours, a nonparametric method that stores the entire training set and classifies new points by majority vote among their closest neighbours. Despite having no parameters to optimize, kNN achieves surprisingly competitive performance and illuminates the geometry of classification in ways that parametric models cannot.
