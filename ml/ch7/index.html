7. Linear Discriminant Analysis

Chapter 7 of 14 25 min read

Beyond naive independence

In Chapter 6, Naive Bayes assumed features are conditionally independent given the class. This made estimation tractable but ignored correlations that are often present in real data. Blood pressure and cholesterol are correlated within both healthy and diseased populations. Word frequencies in documents co-vary systematically. Ignoring these correlations throws away information.

The question Linear Discriminant Analysis (LDA) answers is: can we build a generative classifier that models feature correlations within each class while still producing a simple, interpretable decision boundary?

The answer requires two assumptions: (1) features follow a multivariate Gaussian distribution within each class, and (2) all classes share the same covariance matrix. Together, these assumptions yield a classifier whose decision boundary is exactly linear — hence the name.

The generative model

For binary classification with classes \(c \in \{0, 1\}\), LDA assumes:

\[x | y = c \sim \mathcal{N}(\boldsymbol{\mu}_c, \Sigma)\]

Each class has its own mean vector \(\boldsymbol{\mu}_c \in \mathbb{R}^p\), but both classes share the same covariance matrix \(\Sigma \in \mathbb{R}^{p \times p}\). The prior probabilities are \(\pi_c = P(y = c)\), with \(\pi_0 + \pi_1 = 1\).

The multivariate Gaussian density is:

\[f_c(x) = \frac{1}{(2\pi)^{p/2} |\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(x - \boldsymbol{\mu}_c)^\top \Sigma^{-1} (x - \boldsymbol{\mu}_c)\right)\]

By Bayes' theorem, the posterior probability of class 1 is:

\[P(y=1|x) = \frac{\pi_1 f_1(x)}{\pi_0 f_0(x) + \pi_1 f_1(x)}\]

We classify as class 1 when \(P(y=1|x) > P(y=0|x)\), equivalently when \(\pi_1 f_1(x) > \pi_0 f_0(x)\), equivalently when the log-ratio exceeds zero:

\[\log \frac{\pi_1 f_1(x)}{\pi_0 f_0(x)} > 0\]

Deriving the linear discriminant function

Substituting the Gaussian densities into the log-ratio:

\[\log \frac{\pi_1}{\pi_0} + \log \frac{f_1(x)}{f_0(x)} > 0\]

The normalizing constants \((2\pi)^{-p/2}|\Sigma|^{-1/2}\) cancel because both classes share the same \(\Sigma\). This cancellation is critical — it only happens under the shared-covariance assumption. What remains:

\[\log \frac{\pi_1}{\pi_0} - \frac{1}{2}(x - \boldsymbol{\mu}_1)^\top \Sigma^{-1} (x - \boldsymbol{\mu}_1) + \frac{1}{2}(x - \boldsymbol{\mu}_0)^\top \Sigma^{-1} (x - \boldsymbol{\mu}_0) > 0\]

Expanding the quadratic forms:

\[(x - \boldsymbol{\mu}_c)^\top \Sigma^{-1} (x - \boldsymbol{\mu}_c) = x^\top \Sigma^{-1} x - 2\boldsymbol{\mu}_c^\top \Sigma^{-1} x + \boldsymbol{\mu}_c^\top \Sigma^{-1} \boldsymbol{\mu}_c\]

The \(x^\top \Sigma^{-1} x\) terms appear in both expansions with the same sign and coefficient, so they cancel in the difference. This is the second crucial cancellation that produces linearity. What survives:

\[\log \frac{\pi_1}{\pi_0} + (\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0)^\top \Sigma^{-1} x - \frac{1}{2}(\boldsymbol{\mu}_1^\top \Sigma^{-1} \boldsymbol{\mu}_1 - \boldsymbol{\mu}_0^\top \Sigma^{-1} \boldsymbol{\mu}_0) > 0\]

This is linear in \(x\)! Defining:

\[\boxed{\boldsymbol{w} = \Sigma^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0), \quad b = \log \frac{\pi_1}{\pi_0} - \frac{1}{2}(\boldsymbol{\mu}_1^\top \Sigma^{-1} \boldsymbol{\mu}_1 - \boldsymbol{\mu}_0^\top \Sigma^{-1} \boldsymbol{\mu}_0)}\]

the decision rule becomes: classify as class 1 if \(\boldsymbol{w}^\top x + b > 0\). This is a linear classifier with weight vector \(\boldsymbol{w}\) and bias \(b\), derived entirely from the generative Gaussian assumptions.

Why "discriminant analysis"?

The quantity \(\delta_c(x) = \boldsymbol{\mu}_c^\top \Sigma^{-1} x - \frac{1}{2}\boldsymbol{\mu}_c^\top \Sigma^{-1} \boldsymbol{\mu}_c + \log \pi_c\) is called the linear discriminant function for class \(c\). Classification assigns \(x\) to whichever class has the largest \(\delta_c(x)\). For binary classification, comparing \(\delta_1(x)\) and \(\delta_0(x)\) reduces to the single linear function \(\boldsymbol{w}^\top x + b\) derived above. For multiclass (\(C > 2\)), we compute \(\delta_c(x)\) for each class and pick the maximum — the pairwise boundaries between any two classes remain linear.

Estimating parameters from data

Given training data \(\{(x_i, y_i)\}_{i=1}^n\), the MLE estimates are:

\[\hat{\pi}_c = \frac{n_c}{n}, \quad \hat{\boldsymbol{\mu}}_c = \frac{1}{n_c}\sum_{i: y_i = c} x_i\]

The shared covariance is estimated by pooling the within-class scatter matrices:

\[\hat{\Sigma} = \frac{1}{n - C} \sum_{c=1}^{C} \sum_{i: y_i = c} (x_i - \hat{\boldsymbol{\mu}}_c)(x_i - \hat{\boldsymbol{\mu}}_c)^\top\]

The denominator \(n - C\) (rather than \(n\)) provides an unbiased estimate, analogous to Bessel's correction in univariate variance estimation. Each class contributes its own centered scatter, and pooling across classes enforces the shared-covariance assumption.

Worked example

Binary LDA in two dimensions

Suppose we have \(n = 6\) training points in \(\mathbb{R}^2\) with two classes:

  • Class 0: \(x_1 = (1, 2)\), \(x_2 = (2, 3)\), \(x_3 = (3, 2)\)
  • Class 1: \(x_4 = (4, 5)\), \(x_5 = (5, 4)\), \(x_6 = (6, 5)\)

Step 1: Estimate class means.

\[\hat{\boldsymbol{\mu}}_0 = \frac{1}{3}\begin{pmatrix}1+2+3 \\ 2+3+2\end{pmatrix} = \begin{pmatrix}2 \\ 7/3\end{pmatrix} \approx \begin{pmatrix}2.000 \\ 2.333\end{pmatrix}\] \[\hat{\boldsymbol{\mu}}_1 = \frac{1}{3}\begin{pmatrix}4+5+6 \\ 5+4+5\end{pmatrix} = \begin{pmatrix}5 \\ 14/3\end{pmatrix} \approx \begin{pmatrix}5.000 \\ 4.667\end{pmatrix}\]

Step 2: Estimate priors.

\[\hat{\pi}_0 = \hat{\pi}_1 = \frac{3}{6} = 0.5\]

Step 3: Compute within-class scatter matrices.

For class 0, centered points are \((-1, -1/3)\), \((0, 2/3)\), \((1, -1/3)\):

\[S_0 = \sum_{i \in C_0}(x_i - \hat{\boldsymbol{\mu}}_0)(x_i - \hat{\boldsymbol{\mu}}_0)^\top\]

Computing outer products individually:

  • \((-1, -1/3)^\top(-1, -1/3) = \begin{pmatrix}1 & 1/3 \\ 1/3 & 1/9\end{pmatrix}\)
  • \((0, 2/3)^\top(0, 2/3) = \begin{pmatrix}0 & 0 \\ 0 & 4/9\end{pmatrix}\)
  • \((1, -1/3)^\top(1, -1/3) = \begin{pmatrix}1 & -1/3 \\ -1/3 & 1/9\end{pmatrix}\)
\[S_0 = \begin{pmatrix}2 & 0 \\ 0 & 6/9\end{pmatrix} = \begin{pmatrix}2 & 0 \\ 0 & 2/3\end{pmatrix}\]

For class 1, centered points are \((-1, 1/3)\), \((0, -2/3)\), \((1, 1/3)\):

  • \((-1, 1/3)^\top(-1, 1/3) = \begin{pmatrix}1 & -1/3 \\ -1/3 & 1/9\end{pmatrix}\)
  • \((0, -2/3)^\top(0, -2/3) = \begin{pmatrix}0 & 0 \\ 0 & 4/9\end{pmatrix}\)
  • \((1, 1/3)^\top(1, 1/3) = \begin{pmatrix}1 & 1/3 \\ 1/3 & 1/9\end{pmatrix}\)
\[S_1 = \begin{pmatrix}2 & 0 \\ 0 & 6/9\end{pmatrix} = \begin{pmatrix}2 & 0 \\ 0 & 2/3\end{pmatrix}\]

(Notice \(S_0 = S_1\) in this symmetric example.)

Step 4: Pool to get \(\hat{\Sigma}\).

\[\hat{\Sigma} = \frac{S_0 + S_1}{n - C} = \frac{\begin{pmatrix}4 & 0 \\ 0 & 4/3\end{pmatrix}}{6 - 2} = \begin{pmatrix}1 & 0 \\ 0 & 1/3\end{pmatrix}\]

Step 5: Compute \(\hat{\Sigma}^{-1}\).

Since \(\hat{\Sigma}\) is diagonal, inversion is element-wise reciprocal:

\[\hat{\Sigma}^{-1} = \begin{pmatrix}1 & 0 \\ 0 & 3\end{pmatrix}\]

Step 6: Compute the weight vector \(\boldsymbol{w}\).

\[\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0 = \begin{pmatrix}5 - 2 \\ 14/3 - 7/3\end{pmatrix} = \begin{pmatrix}3 \\ 7/3\end{pmatrix}\] \[\boldsymbol{w} = \hat{\Sigma}^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0) = \begin{pmatrix}1 & 0 \\ 0 & 3\end{pmatrix}\begin{pmatrix}3 \\ 7/3\end{pmatrix} = \begin{pmatrix}3 \\ 7\end{pmatrix}\]

Step 7: Compute the bias \(b\).

Since \(\hat{\pi}_0 = \hat{\pi}_1\), \(\log(\pi_1/\pi_0) = 0\). Computing the quadratic terms:

\[\boldsymbol{\mu}_1^\top \hat{\Sigma}^{-1} \boldsymbol{\mu}_1 = \begin{pmatrix}5 & 14/3\end{pmatrix}\begin{pmatrix}1 & 0 \\ 0 & 3\end{pmatrix}\begin{pmatrix}5 \\ 14/3\end{pmatrix} = 25 + 3 \cdot \frac{196}{9} = 25 + \frac{196}{3} = \frac{271}{3}\] \[\boldsymbol{\mu}_0^\top \hat{\Sigma}^{-1} \boldsymbol{\mu}_0 = \begin{pmatrix}2 & 7/3\end{pmatrix}\begin{pmatrix}1 & 0 \\ 0 & 3\end{pmatrix}\begin{pmatrix}2 \\ 7/3\end{pmatrix} = 4 + 3 \cdot \frac{49}{9} = 4 + \frac{49}{3} = \frac{61}{3}\] \[b = 0 - \frac{1}{2}\left(\frac{271}{3} - \frac{61}{3}\right) = -\frac{1}{2} \cdot \frac{210}{3} = -35\]

Step 8: State the classifier.

\[\text{Classify as 1 if } 3x_1 + 7x_2 - 35 > 0\]

Step 9: Classify test point \(x^* = (3, 4)\).

\[3(3) + 7(4) - 35 = 9 + 28 - 35 = 2 > 0 \Rightarrow \text{Class 1}\]

The decision boundary is the line \(3x_1 + 7x_2 = 35\). Points above/right of this line are classified as class 1; points below/left as class 0.

LDA vs. Logistic Regression

Both LDA and logistic regression produce linear decision boundaries. But they arrive there differently. Logistic regression directly models \(P(y|x)\) via maximum likelihood on the conditional distribution. LDA models \(P(x|y)\) and \(P(y)\) jointly, then derives \(P(y|x)\) via Bayes' theorem.

When the Gaussian assumptions hold exactly, LDA is asymptotically efficient — it uses all available information and converges faster than logistic regression. When the assumptions are violated (non-Gaussian class conditionals, unequal covariances), logistic regression is more robust because it makes fewer assumptions. In practice, both often perform similarly, and the choice comes down to whether you trust the generative model or prefer the safety of direct conditional modeling.

Common mistake

Common mistake: Students sometimes confuse LDA with Quadratic Discriminant Analysis (QDA). QDA relaxes the shared-covariance assumption, allowing each class its own \(\Sigma_c\). Without the shared-covariance constraint, the \(x^\top \Sigma_c^{-1} x\) terms no longer cancel, and the decision boundary becomes quadratic. If a problem specifies "Linear Discriminant Analysis," the shared-covariance assumption is mandatory. Using separate covariance matrices when LDA is requested produces a fundamentally different classifier. Conversely, if the true covariances differ substantially between classes, forcing them to be equal (LDA) introduces bias that QDA avoids at the cost of more parameters.

Edge case

What happens when \(p > n - C\)? The pooled covariance estimate \(\hat{\Sigma}\) has rank at most \(n - C\), so when \(p > n - C\), \(\hat{\Sigma}\) is singular and \(\hat{\Sigma}^{-1}\) does not exist. This is the same singularity problem encountered in OLS (Chapter 2) and resolved by ridge regularization (Chapter 3). The analogous fix for LDA is regularized LDA: replace \(\hat{\Sigma}\) with \(\hat{\Sigma} + \lambda I\) for some \(\lambda > 0\), ensuring invertibility. Alternatively, project the data onto a lower-dimensional subspace first using PCA (Chapter 14) before applying LDA — this combined approach is sometimes called "PCA+LDA" and is common in high-dimensional settings like genomics and image recognition.

Where we go next

LDA produces a linear boundary derived from distributional assumptions. But what if the optimal boundary is inherently nonlinear? Chapter 8 introduces Support Vector Machines, which find the maximum-margin separating hyperplane without any distributional assumptions, and extend to nonlinear boundaries via the kernel trick. SVMs represent a fundamentally different philosophy from the generative models of Chapters 6–7: instead of modeling how data is generated, they focus entirely on the geometry of the decision boundary itself.
