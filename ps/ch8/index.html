8. Continuous Random Variables and Probability Density Functions

Chapter 8 of 12 25 min read

The problem that discrete methods can't solve

In Chapter 7, we described random variables using probability mass functions: \(P(X = x)\) gave a meaningful number for each possible value. But what happens when \(X\) represents something inherently continuous — the exact time until a radioactive atom decays, the precise height of a person, or the real-valued output of a sensor? In these cases, there are uncountably many possible outcomes, and assigning positive probability to any single point would make the total probability infinite (or require infinitesimal probabilities, which standard analysis doesn't support).

So \(P(X = x) = 0\) for every individual \(x\). Does this mean continuous random variables carry no probabilistic information? Clearly not — some regions are more likely than others. We need a new mathematical object that captures "likelihood concentration" without assigning point masses. This object is the probability density function, and it emerges naturally once we ask the right question.

From CDF to PDF: density as a derivative

Even though \(P(X = x) = 0\), the probability that \(X\) falls within an interval \((a, b]\) is perfectly well-defined. Define the cumulative distribution function (CDF) as:

\[ F_X(x) = P(X \leq x) \]

The CDF works for both discrete and continuous variables. For continuous variables, it has two key properties inherited from the axioms of Chapter 2: it is non-decreasing (bigger intervals contain more probability), and it is continuous (no jumps, since no single point carries mass). Moreover, \(F_X(-\infty) = 0\) and \(F_X(\infty) = 1\).

Now ask: how quickly does probability accumulate near a particular value \(x\)? If we look at a tiny interval \([x, x + \Delta x]\), the probability contained in it is approximately:

\[ P(x \leq X \leq x + \Delta x) = F_X(x + \Delta x) - F_X(x) \]

For small \(\Delta x\), if \(F_X\) is differentiable at \(x\), this difference is approximately \(F_X'(x) \cdot \Delta x\) by the definition of the derivative. The quantity \(F_X'(x)\) tells us the rate at which probability accumulates per unit length near \(x\) — it's a density, not a probability. This motivates the definition:

\[ f_X(x) = \frac{d}{dx} F_X(x) \]

This is the probability density function (PDF). Crucially, \(f_X(x)\) is not a probability — it can exceed 1, and its value at a single point has no direct probabilistic meaning. Only integrals of the PDF correspond to probabilities:

\[ P(a \leq X \leq b) = \int_a^b f_X(x)\, dx = F_X(b) - F_X(a) \]

This relationship between differentiation and integration is exactly the Fundamental Theorem of Calculus applied to probability. Every operation we performed with sums in Chapter 7 now becomes an integral; every PMF becomes a PDF; but the logical structure remains identical.

Common mistake: treating \(f_X(x)\) as \(P(X = x)\). Since \(P(X = x) = 0\) for continuous variables, this interpretation is always wrong. Think of \(f_X(x)\) as probability per unit length near \(x\), analogous to physical mass density: the density at a point isn't a mass, but integrating density over a region gives mass.

Properties of valid PDFs

What constraints must a function \(f(x)\) satisfy to be a valid PDF? Two conditions, mirroring the PMF requirements from Chapter 7:

  1. Non-negativity: \(f(x) \geq 0\) for all \(x\). (Since \(F_X\) is non-decreasing, its derivative cannot be negative.)
  2. Normalization: \(\int_{-\infty}^{\infty} f(x)\, dx = 1\). (Since \(F_X(\infty) - F_X(-\infty) = 1 - 0 = 1\).)

Any non-negative function integrating to 1 is a valid PDF for some continuous random variable. Unlike PMFs, there is no upper bound on \(f(x)\): a density can be arbitrarily tall as long as it's narrow enough to keep the total area equal to 1.

Worked example: verifying a candidate PDF

Is \(f(x) = 3x^2\) for \(0 \leq x \leq 1\) (and 0 otherwise) a valid PDF?

Check non-negativity: \(3x^2 \geq 0\) for all \(x \in [0,1]\). ✓

Check normalization: compute the integral:

\[ \int_0^1 3x^2\, dx = 3 \int_0^1 x^2\, dx \]

Apply the power rule for integration (\(\int x^n\, dx = x^{n+1}/(n+1)\)):

\[ = 3 \left[ \frac{x^3}{3} \right]_0^1 = 3 \left( \frac{1^3}{3} - \frac{0^3}{3} \right) = 3 \cdot \frac{1}{3} = 1 \]

The integral equals 1. ✓ Both conditions satisfied, so \(f(x) = 3x^2\) on \([0,1]\) is a valid PDF. Notice that \(f(1) = 3 > 1\) — this is perfectly fine because density values aren't probabilities.

Expectation and variance for continuous variables

The transition from discrete to continuous expectation is mechanical: replace sums with integrals and PMFs with PDFs. For a continuous random variable \(X\) with PDF \(f_X\):

\[ \mathbb{E}[X] = \int_{-\infty}^{\infty} x \cdot f_X(x)\, dx \]

More generally, for any function \(g\):

\[ \mathbb{E}[g(X)] = \int_{-\infty}^{\infty} g(x) \cdot f_X(x)\, dx \]

This is the continuous analog of the Law of the Unconscious Statistician from Chapter 7. Variance follows the same computational formula:

\[ \operatorname{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2 = \int_{-\infty}^{\infty} x^2 f_X(x)\, dx - \left( \int_{-\infty}^{\infty} x f_X(x)\, dx \right)^2 \]

Worked example: mean and variance of \(f(x) = 3x^2\) on \([0,1]\)

Using the validated PDF from above, compute \(\mathbb{E}[X]\):

\[ \mathbb{E}[X] = \int_0^1 x \cdot 3x^2\, dx = \int_0^1 3x^3\, dx \]

Integrate using the power rule:

\[ = 3 \left[ \frac{x^4}{4} \right]_0^1 = 3 \cdot \frac{1}{4} = \frac{3}{4} = 0.75 \]

Now compute \(\mathbb{E}[X^2]\):

\[ \mathbb{E}[X^2] = \int_0^1 x^2 \cdot 3x^2\, dx = \int_0^1 3x^4\, dx \] \[ = 3 \left[ \frac{x^5}{5} \right]_0^1 = 3 \cdot \frac{1}{5} = \frac{3}{5} = 0.6 \]

Apply the computational variance formula:

\[ \operatorname{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2 = 0.6 - (0.75)^2 \]

Compute \((0.75)^2 = 0.5625\). Subtract:

\[ = 0.6 - 0.5625 = 0.0375 = \frac{3}{80} \]

The mean is 0.75 and the variance is 3/80 ≈ 0.0375. Notice the mean (0.75) is greater than the midpoint (0.5) because the density \(3x^2\) increases toward 1, concentrating more mass on the right side of the interval. The low variance reflects that most probability is clustered near 1.

The Continuous Uniform distribution: constant density

What is the simplest continuous distribution? One where probability is spread evenly across an interval \([a, b]\). By normalization, the constant density must be:

\[ f(x) = \begin{cases} \frac{1}{b-a} & \text{if } a \leq x \leq b \\ 0 & \text{otherwise} \end{cases} \]

This is the Continuous Uniform distribution, written \(X \sim \operatorname{Uniform}(a,b)\). Let's derive its mean and variance from scratch rather than memorizing formulas.

Deriving the uniform mean

\[ \mathbb{E}[X] = \int_a^b x \cdot \frac{1}{b-a}\, dx = \frac{1}{b-a} \int_a^b x\, dx \]

Evaluate the integral:

\[ = \frac{1}{b-a} \left[ \frac{x^2}{2} \right]_a^b = \frac{1}{b-a} \cdot \frac{b^2 - a^2}{2} \]

Factor the difference of squares: \(b^2 - a^2 = (b-a)(b+a)\). Cancel \(b-a\):

\[ = \frac{(b-a)(b+a)}{2(b-a)} = \frac{a+b}{2} \]

The mean is the midpoint of the interval — exactly what symmetry demands.

Deriving the uniform variance

First compute \(\mathbb{E}[X^2]\):

\[ \mathbb{E}[X^2] = \int_a^b x^2 \cdot \frac{1}{b-a}\, dx = \frac{1}{b-a} \left[ \frac{x^3}{3} \right]_a^b = \frac{b^3 - a^3}{3(b-a)} \]

Factor the difference of cubes: \(b^3 - a^3 = (b-a)(b^2 + ab + a^2)\). Cancel \(b-a\):

\[ \mathbb{E}[X^2] = \frac{b^2 + ab + a^2}{3} \]

Now apply the variance formula:

\[ \operatorname{Var}(X) = \frac{b^2 + ab + a^2}{3} - \left( \frac{a+b}{2} \right)^2 \]

Expand the squared term: \((a+b)^2/4 = (a^2 + 2ab + b^2)/4\). Find common denominator 12:

\[ = \frac{4(b^2 + ab + a^2) - 3(a^2 + 2ab + b^2)}{12} \]

Expand numerator: \(4b^2 + 4ab + 4a^2 - 3a^2 - 6ab - 3b^2 = a^2 - 2ab + b^2 = (b-a)^2\). So:

\[ \operatorname{Var}(X) = \frac{(b-a)^2}{12} \]

This matches the discrete uniform variance formula from Chapter 7 in spirit: variance scales quadratically with the width of the support. The factor 12 arises from the continuous integration, replacing the discrete factor \((n^2-1)/12\).

The Exponential distribution: modeling waiting times

Suppose events occur randomly over time at a constant average rate \(\lambda > 0\). What is the distribution of the waiting time \(T\) until the next event? Rather than postulating a PDF, let's derive it from a natural assumption: memorylessness. The probability of waiting an additional \(t\) units shouldn't depend on how long you've already waited. Formally:

\[ P(T > s + t \mid T > s) = P(T > t) \quad \text{for all } s, t \geq 0 \]

Define the survival function \(S(t) = P(T > t) = 1 - F_T(t)\). The memoryless condition becomes:

\[ \frac{S(s+t)}{S(s)} = S(t) \quad \Longrightarrow \quad S(s+t) = S(s) S(t) \]

This functional equation has a unique continuous solution (Cauchy's exponential functional equation): \(S(t) = e^{-\lambda t}\) for some \(\lambda > 0\). Therefore:

\[ F_T(t) = 1 - e^{-\lambda t}, \quad t \geq 0 \]

Differentiate to get the PDF:

\[ f_T(t) = \frac{d}{dt}(1 - e^{-\lambda t}) = \lambda e^{-\lambda t}, \quad t \geq 0 \]

This is the Exponential distribution with rate parameter \(\lambda\), written \(T \sim \operatorname{Exponential}(\lambda)\). Memorylessness uniquely characterizes it among continuous distributions — just as the geometric distribution is the unique memoryless discrete distribution (Chapter 7).

Deriving the exponential mean via integration by parts

\[ \mathbb{E}[T] = \int_0^\infty t \cdot \lambda e^{-\lambda t}\, dt \]

Use integration by parts: let \(u = t\), \(dv = \lambda e^{-\lambda t}\, dt\). Then \(du = dt\), \(v = -e^{-\lambda t}\). Apply \(\int u\, dv = uv - \int v\, du\):

\[ = \left[ -t e^{-\lambda t} \right]_0^\infty + \int_0^\infty e^{-\lambda t}\, dt \]

Evaluate the boundary term: at \(t = 0\), \(-0 \cdot e^0 = 0\); as \(t \to \infty\), \(t e^{-\lambda t} \to 0\) (exponential decay dominates polynomial growth). So the boundary term vanishes entirely. The remaining integral:

\[ = \int_0^\infty e^{-\lambda t}\, dt = \left[ -\frac{1}{\lambda} e^{-\lambda t} \right]_0^\infty = 0 - \left( -\frac{1}{\lambda} \right) = \frac{1}{\lambda} \]

The mean waiting time is \(1/\lambda\). Higher rate → shorter expected wait. This reciprocal relationship is fundamental to queueing theory, reliability engineering, and survival analysis.

Worked example: server response times

A web server handles requests with an average response time of 200ms. Assuming exponential response times, what is the probability a request takes longer than 500ms?

The mean is \(1/\lambda = 200\)ms, so \(\lambda = 1/200 = 0.005\) per ms. We want \(P(T > 500)\):

\[ P(T > 500) = 1 - F_T(500) = e^{-\lambda \cdot 500} \]

Substitute \(\lambda = 0.005\):

\[ = e^{-0.005 \times 500} = e^{-2.5} \]

Compute: \(e^{-2.5} \approx 0.0821\).

Approximately 8.2% of requests exceed 500ms. Despite the mean being only 200ms, the exponential distribution's heavy right tail means extreme delays aren't negligible. This is why percentiles (e.g., p99 latency) matter more than means in performance engineering.

Edge case: what happens as \(\lambda \to \infty\)? The mean \(1/\lambda \to 0\) and the PDF concentrates entirely near zero — events happen instantaneously. As \(\lambda \to 0\), the mean diverges and the distribution flattens toward zero density everywhere — events almost never occur. These limits confirm the rate parameter controls temporal scale intuitively.

The Normal distribution: arising from aggregation

Why does the bell curve appear everywhere? Not because nature prefers it aesthetically, but because it's the universal limiting distribution for sums of independent random variables (Central Limit Theorem, Chapter 11). But before we prove that theorem, we need to understand the Normal distribution itself.

A random variable \(X\) follows the Normal distribution with mean \(\mu\) and variance \(\sigma^2\) if its PDF is:

\[ f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left( -\frac{(x-\mu)^2}{2\sigma^2} \right) \]

Written \(X \sim \mathcal{N}(\mu, \sigma^2)\). The special case \(\mu = 0, \sigma^2 = 1\) is the Standard Normal, denoted \(Z \sim \mathcal{N}(0,1)\), with PDF:

\[ \phi(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2} \]

Verifying normalization of the Standard Normal

We need to show \(\int_{-\infty}^{\infty} \phi(z)\, dz = 1\), i.e.:

\[ \int_{-\infty}^{\infty} e^{-z^2/2}\, dz = \sqrt{2\pi} \]

This integral has no elementary antiderivative, so we use a clever trick. Let \(I = \int_{-\infty}^{\infty} e^{-z^2/2}\, dz\). Square it:

\[ I^2 = \left( \int_{-\infty}^{\infty} e^{-x^2/2}\, dx \right) \left( \int_{-\infty}^{\infty} e^{-y^2/2}\, dy \right) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} e^{-(x^2+y^2)/2}\, dx\, dy \]

Convert to polar coordinates: \(x = r\cos\theta\), \(y = r\sin\theta\), \(dx\,dy = r\,dr\,d\theta\), and \(x^2 + y^2 = r^2\):

\[ I^2 = \int_0^{2\pi} \int_0^\infty e^{-r^2/2} \cdot r\, dr\, d\theta \]

The inner integral: substitute \(u = r^2/2\), \(du = r\, dr\):

\[ \int_0^\infty e^{-r^2/2} r\, dr = \int_0^\infty e^{-u}\, du = 1 \]

The outer integral: \(\int_0^{2\pi} 1\, d\theta = 2\pi\). So \(I^2 = 2\pi\), hence \(I = \sqrt{2\pi}\). Dividing by this normalizing constant ensures the PDF integrates to 1.

Standardization: connecting any Normal to the Standard Normal

If \(X \sim \mathcal{N}(\mu, \sigma^2)\), then the transformed variable:

\[ Z = \frac{X - \mu}{\sigma} \]

follows \(\mathcal{N}(0,1)\). This is verified by change-of-variables in the PDF (Jacobian = \(1/\sigma\)), but intuitively: subtracting \(\mu\) centers the distribution at zero, dividing by \(\sigma\) rescales variance to 1. This transformation lets us compute probabilities for any Normal using Standard Normal tables or software:

\[ P(X \leq x) = P\!\left( Z \leq \frac{x - \mu}{\sigma} \right) = \Phi\!\left( \frac{x - \mu}{\sigma} \right) \]

where \(\Phi\) is the Standard Normal CDF. This reduction is why introductory statistics focuses so heavily on \(z\)-scores: they're standardized normals in disguise.

Common mistake: assuming Normality based on visual appearance alone. Many distributions look bell-shaped but have heavier tails (t-distribution, Chapter 9) or skewness. Always test distributional assumptions formally (Chapter 12) rather than relying on eyeball tests. The Central Limit Theorem guarantees approximate Normality for sums, not for individual observations.

Connecting forward

Continuous distributions are the workhorses of statistical inference. The Normal distribution underpins z-tests and confidence intervals (Chapters 11–12). The Exponential connects to Poisson processes and survival models (Chapter 9). Most importantly, the techniques developed here — deriving PDFs from structural assumptions, computing expectations via integration, standardizing to canonical forms — extend directly to multivariate continuous distributions and to the asymptotic theory that justifies frequentist inference. Chapter 9 introduces three more distributions (Poisson, t, chi-squared) that bridge discrete and continuous worlds and complete the toolkit needed for hypothesis testing.
